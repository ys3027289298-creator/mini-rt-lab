# softshadow

`make test` 跑自检（同时也是推导的可执行验证）。

方形面光源 + 旋转方形遮挡体的软影：把可见性近似成**可分离卷积**，与**精确解**
比对并给出误差上界，核宽由几何解析给出、随遮挡体离接收面距离单调变化；核宽为
零时退化为硬影，并在自检与输出中显式记录。

## 模型

二维截面（x、y 各自同样处理）：

| 量 | 含义 |
|---|---|
| `L`  | 方形光源半边长，深度 `zl` |
| `B`  | 方形遮挡体半边长，中心 `(cx,cy)`，旋转 `phi`，深度 `zb` |
| 接收面 | `z = 0`，着色点 `p` |

**精确可见性**：从 `p` 看，遮挡体投影到光源平面上是一个旋转方，半边长
`B*zl/zb`、中心 `O(p) = p*(1-zl/zb) + c*zl/zb`。所以

    V(p) = 1 - area(投影遮挡方 ∩ 光源方) / (4 L^2)

用 Sutherland–Hodgman 凸多边形裁剪求面积（`exact_vis`）。

**卷积恒等式**。设 `f = zl/zb`，`H` 为点光源硬影掩膜（`H=0` 当 `p` 落在半边长
`B*f`、中心 `c*f` 的遮挡阴影方内）。变量替换 `q = O(p)` 得到

    V(p) = 1 - (1/w^2) ∫_{-w/2}^{w/2}∫_{-w/2}^{w/2} H(p + u) du,
    w = 2 L zb / (zl - zb)

即：精确软影 = 对硬影掩膜做宽为 `w` 的**方框模糊**，而方框核可分离，故两次 1D
卷积即可。模块用 1D 核 `k` 近似方框：

* `KERNEL_BOX`：方框本身（对硬影是精确恒等式，仅余离散化误差）；
* `KERNEL_GAUSS`：方差匹配的高斯 `sigma = w/sqrt(12)`（更平滑的半影）。

**核宽随距离**：`w = 2L·zb/(zl-zb)`，遮挡体越靠近接收面（`zb→0`，自检中的
`width_monotone_zb`）越窄，遮挡体越靠近光源（`zb→zl`）越宽；接收面越远
（`zl` 增大，`width_monotone_zl`）越窄。自检还验证：精确可见性 0.1→0.9 的
过渡带宽度 = `0.8 w`（`penumbra_width_matches`），即解析核宽就是真实半影宽度。

## 误差上界

精确结果是 `(K⊗K) * H`，代码计算 `(k⊗k) * (P⊗P * H)`（`P` 为宽 `h` 的像素平均
方框，`k_tilde = k[d]/h` 为采样核的分段常值密度，记 `S = k_tilde * P`）。由于两次
卷积的因子相同：

    (S⊗S - K⊗K) * H = S⊗(S-K)*H + (S-K)⊗K*H

旋转方在每行/列上的截面是区间，其总变差 ≤ 2，故每项 ≤ `2·||S-K||_1`，从而

    max|近似 - 精确| ≤ 2 · ||S - K||_1

代码返回 `bound = 2·||S-K||_1`（`kernel_l1` 对分段线性差解析积分）。自检对多组
场景、两种核、多档分辨率检查 `err ≤ bound`（`box_bound_holds` / `gauss_bound_holds`），
并输出实测 `err/bound`：方框核约 0.2，主要来自一个像素的抹平（`O(h/w)`）；高斯核
约 0.11，主要是方框/高斯真实形状差异（约 0.75）。

## 退化：核宽为零

`w = 0` 发生在点光源（`L = 0`）或遮挡体贴住接收面（`zb = 0`）。此时核退化为单位
冲激，卷积输出 = 硬影掩膜（像素平均）。`RenderStats` 记录 `width`、
`hard_fallback`、`radius`，自检断言 `radius == 0`、输出与掩膜逐像素相等
（`degenerate_identity`）、且不出现超出 `[0,1]` 的过冲。

## 自检输出

`make test` 打印 `name=0/1` 及 `all_ok`，附一条穿过半影的扫描线（精确 / 方框 /
高斯 / 两者误差）和当前 `bound`，便于直接看核宽与误差。
