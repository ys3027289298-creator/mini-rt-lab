# bounce

封闭空间（角落 + 墙面两区）的多次弹射间接光迭代，`make test` 跑自检。

## 模型

- `T`：传输矩阵，元素为 Lambert 反照率 × 形状因子；`E`：直接发射（第 0 次弹射）
- 第 k 次弹射累加 `T^k E` 到间接光，`L_N = E + Σ_{k=1..N} T^k E`，直接光与间接光分开保存
- 收缩因子 `q = ‖T‖∞ < 1`；尾部能量上界
  `r_N = ‖E‖∞·q^(N+1)/(1−q)`，每弹射一次乘 q，单调下降并作为判停残差
- 解析无穷弹射解 `L* = (I−T)⁻¹E`（2×2 显式求逆），逐步核对真实误差不超过残差上界
- `max_bounces == 0` 拒绝执行（`BOUNCE_ERR_ZERO`），并由闭式解给出满足容差的最小可用次数，测试中与暴力枚举互校
- 容差内预算用尽返回 `BOUNCE_ERR_BUDGET`；`‖T‖∞ ≥ 1`（能量不衰减）返回 `BOUNCE_ERR_NONCONTRACT`
