# cylinder

有限开口圆柱（仅侧面）的光线求交，重点解决**细长柱在掠入射/近平行/端面边界处渲染出缺口**的数值问题。
`make test` 跑自检（含 20 万条随机光线的 long double 解析参照差分测试）。

## 1. 二次方程与轴向裁剪

设圆柱基点 `c`、单位轴 `axis`、半径 `r`、轴向区间 `[z0,z1]`，射线 `o + t d`。
把向量投影到垂直于轴的平面，`w_perp = w − (w·axis) axis`，侧面方程是
`|o_perp + t d_perp|² = r²`，展开为二次方程

```
A t² + 2B t + C = 0
A = |d_perp|² = |d|² − (d·axis)²
B = d_perp·o_perp
C = |o_perp|² − r²
```

轴向坐标 `z(t) = (o−c)·axis + t (d·axis)`，`z(t) ∈ [z0,z1]` 给出一个 t 区间 slab，
二次方程的两个根与 slab 求交，取区间内最近根。这一步同时处理了 tmin/tmax 裁剪。

## 2. 两条稳定分支（轴向近退化不丢命中）

`A → 0`（射线与轴近平行）时二次方程退化，通用公式会除以一个很小的 A。
代码按 `A/|d|²` 与阈值 `EPS_PAR = 1e-14`（double 精度极限附近）分两条路径：

- **通用分支**：判别式用交叉积恒等式 `B² − AC ≡ Ar² − |d_perp × o_perp|²`，
  右端两项均非负，是稳定的符号测试；求根用 **q 形式**（`q = −B − sign(B)·√Δ`，
  两根取 `q/A` 与 `C/q`），避免 `−b ± √` 在近切线时的对消丢根。
- **近平行分支**：不除 A、不除 √A，直接在 slab 近端计算
  `R²(Tlo) = C + 2B·Tlo + A·Tlo²`，整条 slab 在柱外才判 miss；
  掠入（`R²` 在表面判定带内）记一次命中。这样近退化时没有任何减法对消或除零路径。

近垂直（`d·axis → 0`）的 slab 分支不做除法，只判断起点轴向位置，是另一侧的退化保护。

## 3. 关键路径用 double 累加

输入、对外接口、回存结果仍是 float，但投影、点积/叉积、判别式与求根在 **double** 中进行。
原因：纯 float 实现下，小半径 + 远起点 + 掠入射会让判别式的两个大项灾难性对消，
实测相对偏差最坏可达 −1.3（噪声比信号大一个数量级），任何有限宽的相对保护带都救不回，
表现为柱子上的缺口。double 把对消余量从 ~1e-7 提升到 ~1e-16。这是业界光线求交的标准做法。

## 4. 误差界

设 `u = 2^-24`（float）、`u_d ≈ 2.22e-16`（double），`γ_n = n u /(1−nu)`。

**后验残差上界**（产品端可直接计算的向后误差）：

```
|A t² + 2B t + C| ≤ (γ16_d + u)·(|A|t² + 2|B|t + |C|) + DISC_GUARD·r²·|A|
```

`γ16_d` 覆盖 double 运算链，`u` 覆盖根回存 float 的量化（实测主导项），
`DISC_GUARD = 8 u_d` 覆盖判别式保护带。

**正向误差上界**（与 long double 解析参照比对），取四项的最大值：

| 项 | 适用情形 | 界 |
|---|---|---|
| (a) 分离根 | 常规 | 向后误差 / `|P'(t)|` |
| (b) 近重根 | 切线，`P'(t)≈0` | `√(向后误差/A)`，O(√u) 而非 O(u) |
| (c) 保护带钳位 | 判别式被钳到 0 | `√DISC_GUARD · r/√A` |
| (d) 近零根翻转 | 最近根在舍入带内过零被 slab 剔除 | 两根间距 `2|B|/A` |

另加 `u·max(1,|t|)` 的回存量化地板。

**slab 边界松弛**：端面处的边界根会因 `z(t)` 舍入被推出区间，按
`4u·(|ta|+|tb|+span)` 向内扩大 slab，只救回误差带内的真命中，不凭空制造命中。

## 5. 测试与实测

- 20+ 个定点用例：径向/切线/内部穿出/slab 与 tmax 裁剪/精确平行/近平行掠入/近垂直/斜轴；
- 差分测试 5 个桶（近平行、近垂直、切线、随机方向、远距小目标），与 80 位 long double
  参照逐射线比对命中一致性和 t 误差；
- 退化输入显式报告：半径为零/负 → `CYL_ZERO_RADIUS`，零轴/非法区间 → `CYL_DEGENERATE`，
  零方向 → `CYL_BAD_RAY`。

实测（gcc/clang，多种子，30M 光线）：**命中判定零 mismatch**，
正向误差/上界 ≤ 1.2e-4，残差/上界 ≤ 0.50，常规命中法线角误差 < 5e-4。

## 返回码

| 码 | 含义 |
|---|---|
| `CYL_HIT` (0) | 命中，结果在 `Hit{ t, p, n }`（法线已朝向光线） |
| `CYL_MISS` (1) | 无侧面命中 |
| `CYL_ZERO_RADIUS` (−1) | 半径为零或负 |
| `CYL_DEGENERATE` (−2) | 轴为零向量或轴向区间非法 |
| `CYL_BAD_RAY` (−3) | 射线方向为零 |
