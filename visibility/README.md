# visibility

球遮挡物前、线段面光源的分段线性可见性：给出近似、误差上界和每段可见占比。
`make test` 跑自检。

## 几何

- 接收点 `P`
- 面光源线段 `L0 → L1`，参数 `s ∈ [0,1]`，采样点 `O(s) = L0 + s(L1−L0)`
- 球形遮挡物 `(C, r)`

对每个光源采样点，阴影射线是 `P + t(O(s) − P)`，`t ∈ (0,1)`。记
`c = C − P`、`v(s) = O(s) − P`，则被遮挡当且仅当射线与球相交：

```
phi(s) = |c × v(s)|² − r² |v(s)|²  ≤  0
```

`phi` 是 `s` 的**二次多项式**（`q2 s² + q1 s + q0`），所以任何区间上的精确
遮挡长度都能闭式求出（`vis_exact` 用作参照）。

## 分段线性近似

把 `[0,1]` 切成 `K` 段，每段长 `h = 1/K`。用两端点的 `phi` 值连线（弦）近似，
弦在 `phi ≤ 0` 上的长度就是该段的遮挡长度。

- 可见占比 `share = 1 − 遮挡长度/h`，写入 `shares[0..K-1]`（`vis_shares`）。
- 总可见率 `visible = 1 − Σ 遮挡长度`（`vis_eval`）。
- `share` 恰为 1 的段**不进积分**：只计入 `n_full`，不加到遮挡和里。

`phi` 的曲率由 `|phi''| = 2|q2|` 精确给出，`M2 = 2|q2|`（含舍入余量）。
每段弦误差 ≤ `M2 h²/8`，于是在 `phi = 0` 的每一侧，弦落入 `[-e, e]`
（`e = M2 h²/8`）的长度就是该段可能被误判的长度。

## 误差证书

`bound = Σ_segments measure{ |chord| ≤ e }`，对所有段都累加（包括被跳过的
share-1 段，否则证书不覆盖整段定义域）。自检验证：

- `|visible − vis_exact| ≤ bound`；
- `|visible − vis_pointwise| ≤ bound + 2/M`（`vis_pointwise` 用 `M` 个等距
  采样点逐点做射线-球求交；每点误差 ≤ 1/M）；
- `bound` 自身以二阶收敛（`bound·K²` 跨倍频程基本不变）。

## 收敛阶

弦误差是二阶的：`e·K²` 在每个倍频程 `[K0, 2K0)` 上平均后基本持平
（一阶方案会每个倍频程翻倍）。单个固定 `K` 的误差依赖相位——弦跨过带边
的偏移不同——所以测试用倍频程均值（spread < 2）来钉死二阶，另外要求任一
固定 `K` 的拟合斜率至少一阶。

## 前置条件与拒绝

`vis_setup` 检查几何，不满足即返回错误码：

- `VIS_ERR_K`：`K ≤ 0`（分段数为零要拒绝）；
- `VIS_ERR_DEGENERATE`：光源零长、`r ≤ 0`、`P` 在球内或球上；
- `VIS_ERR_GEOMETRY`：遮挡物不在 `P` 与光源采样点之间（球在 `P` 后方、
  射线最近点越过光源采样点），或光源线段插进球里。这些情形下单个遮挡物
  只能遮住采样点连线的一部分，二次锥测试与逐点射线测试不再等价。

## 测试输出

参考值示例（`make test`）：

```
half_envelope=0.1740..0.1814 spread=1.04
skew_envelope=0.3862..0.6034 spread=1.56
grazing_envelope=0.2017..0.2036 spread=1.01
raised_envelope=0.3792..0.5148 spread=1.36
sweep_max_step=0.0217 pointwise_max_step=0.0217 worst_gap=0.0002
all_ok=1
```

`sweep_*` 是遮挡物横向扫过时的逐帧变化：分段线性结果的单步跳变不超过逐点
参考的跳变（+ 采样噪声），即不再出现忽明忽暗。
