# lightsample

多光源直接光照的重要性抽样：按贡献推导最优抽样概率，与均匀抽样、按功率抽样比较方差。
`make test` 跑自检（含 40 个光源的场景与 2,000,000 次蒙特卡洛试验）。

## 1. 估计量与概率补偿权重

着色点处，第 i 个光源的直接光照贡献为 C_i（发光 × 几何项 × 可见性），
直接光照真值为

```
μ = Σ_i C_i
```

每次按离散 PDF p_i 抽一个光源 I，概率补偿（重要性权重 w = 1/p_I）后的估计量为

```
X = C_I / p_I
```

无偏性：`E[X] = Σ_i p_i · C_i / p_i = Σ_i C_i = μ`。
任何满足 `p_i = 0 ⇒ C_i = 0` 的 PDF 都保持无偏（零概率只允许分配给零贡献光源）。

## 2. 最优抽样概率：概率与贡献的关系

单样本方差（对任意 PDF 解析成立）：

```
V(p) = E[X²] − μ² = Σ_i C_i² / p_i − μ²
```

在约束 `Σ_i p_i = 1, p_i ≥ 0` 下最小化 Σ_i C_i²/p_i。拉格朗日条件
`−C_i²/p_i² + λ = 0` 给出 `p_i ∝ C_i`，归一化后：

```
p_i* = C_i / Σ_j C_j          —— 抽样概率严格正比于贡献
```

代入得 V(p*) = (Σ_i C_i)² − μ² = 0：知道精确贡献时估计量恒等于 μ，即零方差估计。
任何偏离该比例的 PDF 方差都严格更大（凸函数 1/p 的 Jensen / 柯西不等式可证）。

## 3. 三种 PDF 与工程上的 proxy

实际渲染中 C_i 含未知的可见性项，用不含阴影的贡献 proxy
`c_i = P_i · cosθ_i / d_i²`（功率 × 余弦项 × 距离平方衰减）代替：

| 策略 | 抽样概率 |
|---|---|
| uniform  | `p_i = 1/N` |
| power    | `p_i = P_i / Σ_j P_j`（只看功率，忽略几何） |
| contrib  | `p_i = c_i / Σ_j c_j`（功率 + 几何，不含可见性） |

`c_i = 0 ⇒ C_i = 0`（几何上照不到的点实际贡献也必为零），所以 contrib PDF
给这些光源零概率是安全的；被遮挡但几何可达的光源仍有 `p_i > 0`，估计量不会漏光。

## 4. 方差比较（解析 + 实证）

方差公式 `V(p) = Σ_i C_i²/p_i − μ²` 直接给出解析方差；程序同时用
200 万次抽样实证测量。自检场景（40 个光源，功率跨两个数量级，30% 随机遮挡）结果：

| 策略 | 解析方差 | 实证方差 | 相对 contrib 的方差比 |
|---|---|---|---|
| uniform | 3.19e+02 | 3.19e+02 | 12.21× |
| power   | 1.17e+02 | 1.17e+02 | 4.49× |
| contrib | 2.61e+01 | 2.61e+01 | 1.00× |

两个基线中较优的是 power 抽样：contrib 方差比它低 **4.49 倍**
（标准差低 √4.49 ≈ **2.12 倍**），比 uniform 低 12.21 倍。
解析上 contrib 严格优于两者是数学保证（p* 是唯一最优解，proxy 与 C 同向时
`Σ C_i²/p_i` 随之下降），实证数字与解析值吻合。无遮挡时 `c_i = C_i`，
自检验证方差数值为零（零方差极限）。

## 5. 概率全为零的回退

`build_pdf(weights, p)` 在权重和为零时返回回退标志并令 `p_i = 1/N`：

- 所有光源都在着色点半球之外（cosθ ≤ 0）→ 全部 c_i = 0；
- 场景无有效光源 / proxy 计算结果全零。

回退后估计量退化为均匀抽样，仍然无偏且定义完好（此时 μ = 0 或由其它路径贡献）。
自检以全零权重数组和"所有 proxy 置零的真实场景"两种方式验证回退。
