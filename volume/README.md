# volume

体积介质透射率。光学厚度 `tau = ∫ sigma dt`，透射率始终按 `T = exp(-tau)` 一次求出，
不逐段连乘 `1 - sigma*dt`，因此固定步长下远处也不会产生系统性偏差。

| 接口 | 说明 |
|---|---|
| `transmittance_fixed(m, t0, t1, n)` | 复合 Simpson。一次采样 `4n` 个节点，从同一组值导出 `S(n)`、`S(2n)`、`S(4n)`，`tau` 取 `S(4n)` |
| `transmittance_adaptive(m, t0, t1, opts)` | 递归 Simpson，局部误差 `|S_l + S_r - S| / 15` 驱动细分；`min_depth` 先强制均匀细分，`max_depth` 封顶 |
| `err_tau` / `err_T` | 后验误差估计；因 `\|exp(-a) - exp(-b)\| <= \|a - b\|`（`a,b >= 0`），`tau` 的误差界直接就是 `T` 的误差界，两者相等 |
| `converged` | 误差估计是否落在渐近区。跨间断或被 `max_depth` 截断时置 0，此时界仍给但不可当作严格上界 |
| `Medium.max_sigma <= 0` | 介质为空，直接返回 `T = 1`，零次密度求值 |

## 误差估计与收敛

固定步长在 `n`、`2n`、`4n` 上比较：Simpson 渐近区里相邻差按 16 倍衰减，且
`|S(4n) - S(2n)|` 约为 `S(4n)` 真误差的 15 倍，所以它本身是保守上界。自检里对指数衰减
密度实测该比值恰好是 15，真误差随步长减半按 `h^4` 收敛（比值约 16）。密度有跳变时
相邻差不再按 16 衰减，`converged` 会掉到 0，此时退化为取两个差中较大者，只作提示。

自适应用 `|S_l + S_r - S| / 15` 作为局部误差，向下传 `tol/2` 使两半之和不超过总预算。
这个估计在平坦区间同样为零，所以窄特征藏在初始三点之间时会误判收敛；`min_depth`
的强制均匀细分是唯一的防线，它是启发式而非保证。自检里有一条用例专门复现这个走样：
`min_depth=2` 时微分脉冲被漏掉且 `err_tau` 报 0，`min_depth=8` 才恢复精度。

## 空介质

用调用方给的密度上界 `max_sigma` 判定为空，而不是试探采样——几次采样判定为零，正是
自适应 Simpson 需要 `min_depth` 防范的那种走样。密度全零但上界为正时照常积分，
`exp(-0)` 精确为 1，`zero` 标志置位。零长度段同样直接返回 1。

`make test` 跑自检，覆盖：空密度零次求值、零长度段、常数密度解析解（Simpson 精确）、
指数增长/衰减与正弦密度的解析透射率对比及误差上界、`h^4` 收敛、微分脉冲下固定网格的
远场相对偏差、自适应在充分 `min_depth` 下的精度、跳变密度下 `converged` 置 0。
