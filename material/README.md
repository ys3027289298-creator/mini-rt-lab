# material

`make test` 跑自检。

- `material.c`：Lambert / GGX 求值与余弦加权采样，对解析 cosine 分布做 PDF 校验。
- `albedo_ec.c`：albedo 任一通道 > 1 时的能量修正。按单通道比例整体缩放（保留色相比例）替代逐通道硬裁剪，给出：
  - 修正系数 k、修正前后逐通道反射率；
  - 与解析归一结果的比对误差上界（Lambert 解析积分 + GGX 单次散射数值积分，含确定性与准蒙特卡洛两种独立参考）；
  - 修正引入的色偏指标（渲染反射率的色度 L1 距离）与硬裁剪对照；
  - 无法归一参数的分类报告及原因（NaN/inf、负分量、全零、已在 [0,1]）。
