# material

Lambert + Cook-Torrance GGX 材质，余弦加权采样与 **GGX 重要度采样**，
全部检查在 `make test` 中运行（`-Wall -Wextra`，另过 ASan/UBSan）。

## 1. GGX 分布与采样公式推导

GGX / Trowbridge-Reitz 法线分布（令 `a = rough^2`）：

```
                a²
D(h) = ─────────────────────────────
       π·((n·h)²·(a²−1) + 1)²
```

GGX 按投影立体角归一化：`∫_Ω D(h)(n·h) dω_h = 1`，
因此半矢量概率密度为 `p_h(h) = D(h)(n·h)`（已由数值积分在 r=0.25/0.5/0.9 上验证 = 1）。

各向同性瓣与方位角无关，`φ_h = 2π·u2`。对 `p_h` 在方位角上积分，
用 `tan²θ = (1−cos²θ)/cos²θ` 换元，得到 θ 的边缘 CDF：

```
              tan²θ
P(θ) = ─────────────────
        a² + tan²θ
```

令 `P(θ) = u1` 反解（代码里直接用 cos² 形式，避免 θ→π/2 时 tan 发散）：

```
                    1 − u1
cos²θ_h = ───────────────────────
          1 + (a² − 1)·u1

h = (sinθ cosφ, sinθ sinφ, cosθ)
```

对应实现：`ggx_sample_half()`。

## 2. 方向 PDF 与 BRDF 的乘积（估计量）

渲染积分量的是入射方向 `wi`，反射映射 `wi = 2(wo·h)h − wo` 的
雅可比为 `|dω_h/dω_i| = 1/(4 wo·h)`，故

```
              D(h)(n·h)
p(wi) = ─────────────────          （ggx_dir_pdf / ggx_sample_wi）
            4 (wo·h)
```

Monte Carlo 估计量 `w = f·cos_i / p(wi)`。代入
Cook-Torrance `f = DGF / (4 cos_i cos_o)`，D 恰好约掉：

```
        F·G·(wo·h)
w = ───────────────────              （ggx_estimator_weight）
      cos_o·(n·h)
```

测试 `ggx_estimator_identity` 对 64 组随机方向逐点验证
`f·cos/p` 与闭式权重一致；`ggx_jacobian_pdf` 验证采样返回的 pdf、
`ggx_dir_pdf()` 与 `p_h/(4wo·h)` 三者逐点相等。

## 3. 与解析 PDF 逐点比对（30 万样本直方图）

把采样得到的半矢量按 θ 分 48 个 bin，与解析分布比对：

- **Pearson χ²**：r=0.40 时 χ²=69.4 / dof=48，r=0.10 时 49.2 / 48，
  均远低于 2·dof 阈值（尾 bin 期望计数只有个位数，必须用 χ² 而非逐 bin 相对误差）；
- **CDF 逐点**：最大累计误差 0.0014 / 0.0004，低于蒙特卡洛容差 `4/√N = 0.0073`；
- **密度逐点**（瓣宽足以分辨 bin 的 r=0.40）：峰值区域最大相对误差 2.5%。

窄瓣（r=0.10）下 bin 宽超过瓣宽，中点密度的矩形近似本身失效，
此时以解析 CDF 之差给出的期望计数为准（χ² 检查）。

## 4. 同等样本下的方差数据

视角 45°，F0=0.04，每像素 SPP=64，500 次独立试验估计估计量方差，
积分目标 `∫ f(wi,wo)·cos_i dω_i`：

| rough | 余弦采样均值 | GGX 采样均值 | 余弦采样方差 | GGX 采样方差 | 方差比 | 标准差下降 |
|---|---|---|---|---|---|---|
| 0.10 | 0.00839 | 0.01053 | 1.26e-03 | 7.1e-10 | **1.78e6 ×** | 1333 × |
| 0.25 | 0.01090 | 0.01065 | 8.65e-05 | 2.1e-08 | **4143 ×** | 64 × |
| 0.50 | 0.00993 | 0.00986 | 4.48e-06 | 2.3e-07 | **19.4 ×** | 4.4 × |

两种采样的均值在粗粗糙度下一致（`two_methods_agree`），无偏性保持；
瓣越窄收益越大——余弦采样几乎打不中窄高光瓣，这正是高光形状破碎的根因。

## 5. rough = 0 的特例（δ 分布）

`a → 0` 时 `D(h)` 退化为 δ(h−n)，不再是普通密度函数，不能走通用公式：

- `ggx_ndf()` 在 rough=0 时返回 0（除极点外密度处处为 0），不产生 NaN/Inf；
- `ggx_sample_half()` 对任何随机数确定性返回 `h = n`，
  `ggx_sample_wi()` 走显式镜像分支 `wi = reflect(wo, n)`；
- pdf 不有限：`ggx_*_pdf()` 返回 0，调用方不得按普通估计量 `f·cos/p` 除；
- 估计量取极限（G→1, h→n）：`w = F(n·wo)`，即纯镜面反射只乘菲涅耳项
  （`zero_rough_weight_is_fresnel` 验证）；
- 另验证 r=0.02 时采样瓣平均极角 < 0.05 rad，确认瓣随 rough→0 收敛到法线。

实践中通常把 roughness 钳到 1e-3 左右保留有限 pdf，精确镜面则走上述镜像分支。
