# adaptive

按块方差的自适应采样，`make test` 跑自检（确定性输出，含 32 个断言）。

## 模型

`[0,1)^2` 域切成 8×8 共 64 块；中心一个圆盘模拟高光，盘内块以 0.30
概率取高值 8.0、否则取 0.1（盘外概率 0.01）。盘内块方差远大于盘外，
均匀采样时噪点集中在高光处。

## 流程

1. **试点采样**：每块 32 个样本，Welford 在线估计均值/方差。
2. **按方差分配**：剩余 4096 个预算按 `n_i ∝ var_i` 分配（Hare 配额
   保证整数样本恰好分完；无方差信号时退化为轮询）。
3. **目标误差反解**：标准误 `eps`、置信因子 `z` 下
   `n = (z·σ/eps)²`。`eps <= 0` 或 NaN 一律拒绝（返回 -1）——零误差
   需要无穷多样本，没有有限方案能保证。
4. **等预算对比**：均匀与自适应都用 6144 个样本，独立重复 8 次，分别
   报告总 MSE、高光区 MSE、最差块 MSE 及自适应/均匀的比例。
5. **误差分布图**：ASCII 热图（均匀 vs 自适应的块误差、各块样本数），
   另写 `error_se.pgm`、`samples_n.pgm` 两张 PGM 灰度图，并给误差分位数。
6. **收敛报告**：对给定目标误差逐块检查估计标准误，超目标的块逐个列出
   坐标、已用样本数、当前标准误和所需样本数，并汇总达到目标所需总样本。

## 一个要诚实说明的点

固定总预算下，`n ∝ σ²` 会把各块的平方误差**拉平**，因此高光块和最差块
误差大幅下降，但总 MSE 的理论最优分配是 Neyman 的 `n ∝ σ`。自检同时给
总误差、高光区误差和最差块误差三组比例，并在输出里用 oracle 预测验证
`n ∝ σ²` 对总 MSE 只是重新分配（理论比例 1.0），不拿单一好看的数字
掩盖这个事实。本场景实测总 MSE 同样下降，是因为试点估计的有限样本效应
让冷块实际少花了样本。

## 典型结果

| 指标 | 均匀 | 自适应 | 比例 |
|---|---|---|---|
| 总 MSE | 0.0133 | 0.0070 | 0.53 |
| 高光区 MSE | 0.109 | 0.016 | 0.15 |
| 最差块 MSE | 0.253 | 0.057 | 0.23 |

`eps=0.10` 时 10/64 块未收敛（达到目标共需 8964 样本，预算 6144 不够）；
`eps=0.30` 时全部收敛，仅需 1004 样本。
