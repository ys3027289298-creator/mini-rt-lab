# adaptive

按**样本方差驱动的逐像素自适应终止**：蒙特卡洛积分在固定检查点上用经验
Bernstein 半宽判定停止，并对"提前终止偏差"给出可证明的上界。`make test`
跑自检，每像素明细写入 `artifacts/adaptive_pixels.csv`（可用 `make test CSV=路径`
覆盖，目录不存在时 Makefile 自动创建，程序打开失败会打印 `csv_open_failed`）。

## 停止判据

每像素维护 Welford 在线均值/无偏方差，在预先固定的几何检查点序列
（8, 10, 12, …, 2048，共 k=26 个）上评估：

- **eb（经验 Bernstein，主判据）**：样本取值范围 R = 1，显著性 α = 0.05，
  半宽
  ```
  h(n) = sqrt(2 s_n² · ln(2k/α) / n) + (2R/3) · ln(2k/α) / n
  ```
  当 `h(n) ≤ tol`（tol = 0.03）时停止，否则采样到 n_max = 2048。
- **naive（对照，过松判据）**：`h(n) = 1.96 · sqrt(s_n²/n)`，正态近似、
  无范围修正项，同样以 tol = 0.03 停止。它在小样本/重尾场景会欠覆盖，
  自检会把超界比例如实报告出来。

两条判据共用同一条样本流（每像素无论是否提前停止都采满 n_max 个样本），
因此全样本参考值与提前终止估计是**配对**的，RNG 推进不受终止影响，
同种子重跑逐位一致（自检项 `rerun_bit_identical`）。

## 偏差上界证明

设像素真值为 μ，第 n 个检查点的样本均值 X̄_n、无偏方差 s_n²，样本取值落在
长度 R 的区间内。

**引理（经验 Bernstein / Maurer–Pontil 2009，无偏方差形式）**：对任意
n ≥ 2 与 t > 0，

  Pr[ |X̄_n − μ| ≥ sqrt(2 s_n² t / n) + (2R/3)(t/n) ] ≤ 2 e^{−t}。

**1. 单点覆盖。** 取 t = ln(2k/α)，令 h(n) 为上面 eb 判据的半宽，则

  Pr[ |X̄_n − μ| > h(n) ] ≤ α/k。

**2. 检查点并集界。** 停止时刻 τ 是数据相关的，但它只能取固定检查点
{n_1,…,n_k}（含 n_max）。对全部检查点做并集界：

  Pr[ ∃ j : |X̄_{n_j} − μ| > h(n_j) ] ≤ Σ_j α/k = α。

**3. 提前终止偏差界。** 判据仅在 h(τ) ≤ tol 时停止。由引理，以概率
≥ 1 − α 有 |X̄_τ − μ| ≤ h(τ) ≤ **tol**；超出该事件时代价至多为 R：

- 高概率界：Pr[ 提前停止且 |X̄_τ − μ| > tol ] ≤ **α = 0.05**；
- 条件期望绝对偏差界（好事件代价 ≤ tol、坏事件代价 ≤ R 的三角形不等式）：

  E[ |X̄_τ − μ| | 停止 ] ≤ **tol + Rα = 0.03 + 0.05 = 0.08**。

- 采到 n_max 仍未满足 tol 的像素，好事件上界换成实际半宽 h(n_max)，
  即 E[偏差 | 采满] ≤ E[h(n_max)] + Rα，自检项
  `eb_exhausted_expected_bias_bound` 在存在此类像素时验证。

注意 naive 判据没有范围项，引理不适用——它名义上的 95% 覆盖在小样本下
没有保证，这正是对照实验要暴露的情形。

## 实测结果（2000 像素/场景，3 个解析可积场景）

| 场景 | 判据 | 提前终止比例 | 平均停止样本数（节省） | RMSE / 全样本 RMSE | 真值超 tol 比例 | 检查点并集超界 |
|---|---|---|---|---|---|---|
| quad (u², 真值 1/3)  | eb    | 100% | 1776（13%） | 1.06× | **0%** | 0.05% |
| quad                 | naive | 100% | 434（79%）  | 2.23× | 4.0% | 36.95% |
| sine (sin πu, 2/π)   | eb    | 100% | 2035（0.6%）| 1.01× | **0%** | 0.05% |
| sine                 | naive | 100% | 446（78%）  | 2.09× | 3.75% | 36.80% |
| spike (1[u<.05])     | eb    | 100% | 1130（45%） | 1.35× | **0%** | 0.80% |
| spike                | naive | 100% | 83（96%）   | **8.67×** | **67.05%** | 68.85% |

读法：

1. **偏差不超上界**：eb 在三个场景的提前停止超界率均为 0%，检查点并集
   超界率 0.05–0.80%，均远低于 α = 0.05，`eb_*` 全部断言通过；条件期望
   偏差实测 ≤ 0.0057，远小于证明上界 0.08（界是保守的）。
2. **过松判据的代价被如实报告**：naive 在光滑场景就有约 4% 的 tol 超界
   （名义 5% 水平，尚可），但在 spike 这种伯努利型稀疏被积函数上，前 8 个
   样本全为 0 时样本方差为 0、判据立刻停在最小样本数，**67% 的像素偏差
   达到 0.05（=真值本身），RMSE 恶化到全样本的 8.67 倍**。
   `naive_loose_threshold_reported=1` 保证这类超界不可能被静默吞掉。
3. **与全样本的配对差**：eb 的逐像素差最大 0.017、RMSE ≤ 0.0045，始终
   小于 tol；naive 在 spike 上逐像素差最大 0.067。
4. 配对比较（`tools/analyze.py`）：spike 上 1838/2000 个像素 naive 偏差
   大于 eb——naive 省下的 96% 样本是以三分之二像素出界换来的。

## 自检断言清单

- `eb_union_bound_held`：eb 出现任意检查点超界的像素比例 ≤ α + 抽样余量；
- `eb_early_viol_within_alpha`：提前停止像素的真值偏差超 tol 比例 ≤ α；
- `eb_early_expected_bias_bound` / `eb_exhausted_expected_bias_bound`：
  两类像素的经验期望偏差 ≤ 各自证明上界；
- `eb_achieves_early_stops`：判据确实产生样本节省（避免 tol 设成不可达）；
- `naive_loose_threshold_reported`：spike 上 naive 必须报告超界；
- `eb_rmse_not_blown_up`：eb 的 RMSE 相对全样本参考不超过 3 倍
  （naive 无此保证，其 `rmse_ratio` 只打印不断言，作为反例证据）；
- `checkpoints_ordered`、`welford_mean/var`、`rerun_bit_identical`：
  调度、数值与可复现性结构检查。

## 文件

- `src/adaptive.c`：判据、Welford 累加器、检查点调度、全部自检；
- `tools/analyze.py`：纯标准库（`python3 -I`）汇总停止样本数分位数、
  偏差分位数、超界率与 eb/naive 配对比较；
- `artifacts/adaptive_pixels.csv`：12000 行逐像素记录（场景、判据、像素、
  是否提前停止、停止样本数、提前估计、全样本估计、真值、两种偏差、两个
  超界标志）。
