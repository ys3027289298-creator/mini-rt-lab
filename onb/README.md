# onb

由表面法线构造正交基（ONB），解决余弦加权采样在法线接近世界轴时
切向翻转、采样方向被镜像的问题。

`make test` 跑自检；`make plot` 生成 `out/onb_curves.png` 与两个 CSV。

## 三种构造

| 函数 | 做法 | 条件数 | 极轴行为 |
|---|---|---|---|
| `build_onb_fixed` | `normalize(z × n)`，固定世界 z 作辅助轴 | κ = 1/sin∠(n,z)，极轴发散 | 返回 `ONB_DEGENERATE` |
| `build_onb_stable` | 选与 n 最垂直的坐标轴做辅助轴（PBRT 式分支） | κ ≤ √2（单位法线最小分量 ≤ 1/√3） | 始终给出合法框架 |
| `build_onb_quat` | 把 +z 最短弧旋转到 n 的四元数，旋转标准基 | 参考实现，−z 奇点单独处理 | 180° 绕 x 特判 |

另有 float 版本 `build_onb_fixedf` / `build_onb_stablef`，以及策略包装
`build_onb_safe`：

1. 法线模长为零（或含 NaN/Inf）→ 拒绝，返回 `ONB_ZERO_NORMAL` /
   `ONB_NONFINITE`，绝不静默返回零向量框架；
2. 先走固定构造；
3. κ > `KAPPA_LIMIT`（1e4）或正交残差 > `RESID_LIMIT`（1e-12）→
   置 `ONB_KAPPA_HIGH` / `ONB_RESID_HIGH` 并切到稳定构造；
4. 极轴处固定构造退化 → 同样回退，状态保留 `ONB_DEGENERATE`。

## 与四元数基的逐向量误差及上界

共享同一法线的两个右手框架只相差一个绕法线的扭转，因此误差分两层：

- **原始逐向量误差** ‖v_F − v_Q‖：包含两构造参考切向选择不同带来的
  O(1) 几何扭转，与 κ 无关，平凡上界为 2（单位向量逐分量差）；
- **扭转对齐误差**：先在切平面内把四元数框架扭转到同一参考切向，
  剩下的纯数值舍入满足

      err ≤ C · ε · κ,   C = 2（double）/ 4（float）

  常数由 2×10⁶ 个随机法线实验标定（观测最大比值 0.77 / 0.44），
  留 2 倍以上余量；自检在双/单精度下逐条验证该上界。

## 曲线图（`out/onb_curves.png`，四联）

1. 双精度扭转对齐误差 vs κ：固定构造误差相对 ε·κ 有界，蓝色解析上界
   随 κ 线性放大；绿线为稳定构造，聚集在轴左端（自身 κ ≤ √2）；
2. 单精度同一条律，ε 大约是双精度的 1e9 倍；
3. 原始逐向量误差：O(1) 几何扭转，不随 κ 发散；
4. 法线扫过 +z 极轴时固定构造切向量变号（翻转），稳定构造保持连续。

数据文件：`out/sweep.csv`（κ 扫描，含残差、两层误差、上界）、
`out/flip.csv`（极轴两侧切向量分量）。
