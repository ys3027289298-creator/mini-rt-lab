# ao

余弦加权半球环境遮蔽（ambient occlusion），单文件 C 自检，`make test` 运行。

## 估计量

着色点 `p`、法线 `n`、遮蔽半径 `r`，在 `n` 的切空间里做余弦加权半球采样，
pdf = cosθ/π。AO 积分的被积函数带一个 cosθ，与 pdf 中的 cosθ 恰好约掉，
因此每个被接受的探针直接贡献距离衰减项：

```
occluded (t < r):  w = 1 - t/r      // 贴着表面的遮挡物贡献 1，半径边界贡献 0
miss (t >= r):     w = 0
A = mean(w_i)                        // 估计值，取值 [0,1]
```

`ao_probe()` 先检查余弦权重 `dot(wi, n)`：非正（下半球或切平面内）直接返回
拒绝，`ao_estimate()` 补采直到拿到 N 个接受样本。自检里用一个均匀球面的
对抗采样流验证拒绝路径——它有约一半方向落在切平面以下。

## 场景与解析参考

测试场景由无限平面和 AABB 墙组成，遮挡射线做最近命中（slab 求交）。

无限天花板平面（点到平面距离 d，AO 半径 r，d < r）有闭式解：

```
E[X] = (1/π) ∫_{t<r} (1-t/r) cosθ dω = (1 - d/r)²
```

单探针方差同样有闭式形式（令 c = d/r）：

```
E[X²] = 1 - 4c + 3c² - 2c² ln c
Var(X) = E[X²] - E[X]²
```

自检同时核对高样本蒙特卡洛均值与方差是否落在解析值的容差内；没有解析解的
角落双墙场景则用 4×16384 的高样本参考代替真值。

## 收敛性与误差上界

估计量是 N 个独立 [0,1] 随机变量的均值，RMSE 理论上按 1/√N 下降。自检在
N = 16…4096 九个量级上各跑 200 次独立试验，检查：

- 每翻倍一步的 RMSE 比值落在 (0.50, 0.95)，理论值 1/√2 ≈ 0.707
- RMSE 对 N 的 log-log 斜率接近 -1/2（实测约 -0.50）
- 256 倍样本对应约 16 倍噪声下降
- 实测 RMSE 与解析预测标准误差 √(Var/N) 同量级

误差上界用两个不依赖分布形状的不等式（δ = 0.05），以 200 次试验的实际覆盖率
验证（要求 ≥ 93%）：

- Hoeffding：ε = √(ln(2/δ) / (2N))，只用到取值 [0,1]
- 经验 Bernstein：ε = √(2 s² ln(2/δ) / N) + 7 ln(2/δ) / (3(N−1))，
  利用样本方差 s²，小样本时更紧

角落场景另外验证 64 样本估计相对高样本参考的 Hoeffding 覆盖率，以及低样本
均值随样本数向参考收敛。随机源是固定种子的 xorshift32，整个自检可逐位复现。
