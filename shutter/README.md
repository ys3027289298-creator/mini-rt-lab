# shutter

快门区间时间采样实现运动模糊。硬边盒状足迹物体沿恒定运动矢量线性运动，
在快门区间 `[t0, t0+dt)` 上做时间分层采样，按每个样本覆盖的运动矢量段长度给权重，
并与解析运动模糊（盒卷积积分，梯形响应）比对。

`make test` 跑自检，覆盖：

- 快门时长 `dt <= 0`（含零快门）、样本数 `n <= 0` 拒绝，返回 `-1`
- 权重归一且为正、采样时刻落在快门区间内、样本位置落在运动矢量上
- 静止物体（`v=0`，零长度运动矢量）退化为等权、无模糊的瞬时足迹
- 解析积分的平台/斜坡/对称性，以及能量守恒（空间积分等于物体宽度 `2r`）
- 分层中点法的确定性误差上界 `|err| <= 2/N`：被积函数只取 0/1、至多两个跳变沿，
  至多两个分层出错，每层误差不超过其权重 `1/N`；误差随 `N` 增大严格下降
- 非均匀时间单元按运动矢量段长度加权，误差上界为 `2 * max(单元权重)`
- 抖动采样的经验 RMSE 随 `N` 增大而下降
- 单时间样本只输出 0/1，复现硬边拖影；多样本在斜坡区给出软过渡
