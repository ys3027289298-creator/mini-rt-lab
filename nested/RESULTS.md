# 实验结果：玻璃壳内小球的连续光路追踪

场景：玻璃球 R=1、IOR=1.5；内层 Lambertian 球 r=0.55、中心偏移 (0.10, 0.06, 0.08)。
320×320，正交相机，种子 20261124。两种反照率 rho ∈ {0.25, 0.75}。

## 1. 从 rho 推出的终止参数

每穿透内层一次吞吐量乘 rho，K 次后残余 rho^K；要求其低于 8 位输出的一个
量化步长 LSB = 1/255：

| rho | K = ceil(ln LSB / ln rho) | tau = rho^K | 校验 |
|---|---|---|---|
| 0.25 | **4** | **0.003906** | 0.25³ = 0.0156 > LSB，0.25⁴ = 1/256 < LSB |
| 0.75 | **20** | **0.003171** | 0.75¹⁹ ≈ 0.00423 > LSB，0.75²⁰ ≈ 0.00317 < LSB |

反照率越高，能量衰减越慢，需要的穿透上限越大——两个数都是 rho 的函数，
没有经验旋钮。

## 2. 两次渲染的内层边缘切块统计（SPP=64）

切块判据（全部从图像自身推出，无魔数）：以 walk 推导参数渲染为参考；
**gap** = 参考剪影内测试渲染完全没到达的像素（硬缺口）；**diff-block** =
亮度与参考相差超过参考内部 MC 噪声 floor 的 3σ（最小 2 个码值）的像素。
统计区域为参考剪影腐蚀 2px 后的边缘带（每组 2640 px 左右）。

| 渲染 | gap@edge | diff-block@edge | 边缘带亮度均值差 (码值) |
|---|---|---|---|
| rho=0.25 buggy（一次求交） | **1545** | **1549** | −4.30 |
| rho=0.25 walk（连续追踪，K=4, tau 推导值） | 0 | 0 | 0.000 |
| rho=0.75 buggy | **1545** | **1704** | −3.04 |
| rho=0.75 walk（K=20, tau 推导值） | 0 | 0 | 0.000 |

边缘裁剪图：`renders/exp/rho{0.25,0.75}/analysis64/buggy.edge.png`
（红=缺失像素，橙=亮度差异块）；全景对比
`renders/exp/rho0.25_spp64_buggy_vs_walk.png`：buggy 图里玻璃壳完全消失、
内层球像贴上去的硬边圆盘；walk 图恢复了折射亮环与 TIR 条纹。

SPP=1 时硬切块逐像素可见（`analysis1/`）：两组 buggy 各有 240 个边缘
gap 像素，walk 参考为 0。

## 3. 提高穿透上限后切块数不降 ⇒ 阈值诊断

在每个 rho 下对 cap ∈ {1,2,4,8,16} 做扫描，三种阈值并列对照
（SPP=1，被终止的路径直接成为黑像素，效应不被平均掉）：

- **推导 tau**（0.00391 / 0.00317）；
- **过低 tau** = LSB/100 = 0.0000392（阈值几乎不生效，cap 单独起作用）；
- **过高 tau** = rho/2（0.125 / 0.375，第一次穿透后残余能量仍有
  rho ≫ LSB 时就终止）。

边缘带 diff-block 像素数：

| cap | rho=0.25 过低 tau | rho=0.25 过高 tau | rho=0.75 过低 tau | rho=0.75 过高 tau |
|---|---|---|---|---|
| 1 | 89 | **89** | 144 | **144** |
| 2 | 0 | **89** | 8 | **8** |
| 4 | 0 | **89** | 0 | **0**¹ |
| 8 | 0 | **89** | 0 | **0**¹ |
| 16 | 0 | **89** | 0 | **0**¹ |

¹ rho=0.75 过高 tau=0.375 略低于第二次穿透后的吞吐量 rho²=0.5625，
k≥4 的 0 来自 cap 先于阈值生效；事件计数显示阈值侧仍有 2 次 taukill，
而低 tau 侧为 0。

**对照结论**：阈值给对（或偏低）时，切块数随 cap 提高单调降到 0；
阈值给高时，rho=0.25 组切块数在所有 cap 下恒为 89——提高穿透上限
完全无效，因为路径是被 tau 提前杀死的（k≥2 时 taukill=1262，
capkill=0），再大的 cap 也救不回来。这正是"提高 cap 后切块数不降"
的诊断信号。

### 关于阈值方向的说明

任务假设的情形是"能量阈值设得过低"。在本实现的终止语义
（吞吐量低于 tau 即弃路径）下，数值实验表明因果方向相反：**tau 过高**
才会在能量仍可见时终止路径并产生 cap 无法消除的切块；**tau 过低**
不会产生额外切块，只是让本可提前结束的路径继续追踪、白做计算
（rho=0.25 低 tau 扫描到 k=16 时 taukill 仅 2 次、capkill=0）。
因此并列对照中把三个区间都列出：过低 tau 的行为与推导值一致（切块
随 cap 收敛），只有过高 tau 出现 cap 不敏感的恒定切块。推导值
tau=rho^K ≤ LSB 恰好卡在"再低只是浪费、再高就有可见误差"的边界上。

## 4. 推导参数下的终止事件（SPP=64 全图）

| rho | K | capkill | taukill | 内层命中总数 |
|---|---|---|---|---|
| 0.25 | 4 | 10 | 0 | 2,340,225 |
| 0.75 | 20 | 0 | 0 | 2,340,225 |

cap 与 tau 在推导值下几乎从不触发：物理上 Lambertian 漫反射后光线
极少重新命中内层球，K 层穿透是一个严格但便宜的安全上限。
