# spectrum

波长重要性采样的光谱渲染：光谱功率分布 → CIE XYZ → sRGB，并与稠密参考比对给误差上界。

`make test` 跑自检（约 1 秒）；`make image` 另出 `grating.ppm`（光谱光栅色带）。

- 波长重要性采样：360–830 nm 上分桶，按 `|P(λ)|·(x̄+ȳ+z̄)` 定目标分布，2% 底保底；每桶内均匀采样，整体分层。
- 光谱功率分布：等能、D65 反射、5800 K 黑体、窄带（谱线 / 光栅方向）。
- 误差上界：统计项 `3·se` + 截断项 `∫|P|·CMF`（采样区间外）+ CIE76 色差上界（XYZ 盒的角点包络）+ 显示级（sRGB 矩阵与 gamma 斜率）。
- 自检断言：观测误差落在上界内、样本数增加时 dE 与上界收敛、截断项覆盖被丢掉的颜色、参考积分加密后不变、色相随波长单调（紫→蓝→青→绿→黄→橙→红）、固定波长采样对照在同一批窄带下 dE>10。
- 波长区间非法（非有限 / 空 / 超出 360–830 nm / 窄于步长）时拒绝估计，报出合法上下界。
