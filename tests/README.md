# tests — 最小自建测试入口

无第三方测试库。两个测试 C 文件通过 `#include` 直接编译被测源码，并用
`#define main xxx_demo_main` 把各模块自带的演示 `main` 改名，从而能访问
`static` 内部函数。

| 文件 | 覆盖路径 |
|---|---|
| `bvh_test.c` | 几何求交：`aabb_hit` slab 求交、`build` 中位数分裂建树、`aabb_area`/容量边界 |
| `material_test.c` | 材质求值：Lambert、GGX NDF、余弦加权采样与 PDF |
| `mutate_test.py` | 变异（人为注入缺陷）框架，仅用 Python 标准库 |
| `baseline/*.sha256` | 三个 demo 成功路径输出的逐字节哈希 |

## 用法

```sh
make test            # 编译并运行两个测试入口（全绿退出码 0）
make check-baseline  # 重跑 bvh/material/sample 三个 demo，校验输出与基线逐字节一致
make mutation        # 注入 24 处缺陷，统计捕获率
```

## 测试方法

* **独立 oracle，不与被测代码共享实现**
  * 几何：用除法形式 + `fmax/fmin` 归约重写的 slab 求交 `ref_box_hit`，
    在两个场景（轴对齐网格、抖动/重叠盒）上对 300 条确定性随机射线、
    每条对每个图元及合并盒逐一比对命中判定与入口距离。
  * GGX：分层蒙特卡洛积分 `2π·E[D·cos]` 必须归一化为 1（N=4096，≈0.999995），
    参考常数由独立的 Python 实现给出。
* **边界用例**：平行/零分量射线、负方向、tmax 裁剪（含边界）、掠射角、
  退化/倒置包围盒、容量上限、采样极点 u1=0、已知精确采样点。
* **结构校验**：根盒覆盖、子节点并集、叶子图元集合完整且唯一、质心中位数
  严格 `<` 分裂、最宽轴选择、等质心回退不撑爆节点表。

## 变异结果（24 处注入缺陷）

| 模块 | 捕获 | 捕获率 |
|---|---|---|
| bvh.c | 12/12 | 100.0% |
| material.c | 11/12 | 91.7% |
| **总计** | **23/24** | **95.8%** |

每条变异都是对源码的一处精确文本替换（锚点唯一），在临时沙箱中编译，
不修改真实源码。被杀死（KILLED）= 测试退出非零；存活（SURVIVED）= 仍通过。

### 唯一漏网缺陷及原因

* **M9（`cosine_sample` 删除 `norm3` 归一化）存活**：这是单精度下的真实
  盲区，不是用例缺失。采样向量本就由 `r=sqrt(u1)`、`z=sqrt(1-u1)` 构造，
  在 `float` 运算下 r²+z² 已等于 1（实测长度偏差仅 ~1e-7），`norm3` 在
  float 精度内是恒等操作。实测：删除归一化后最大长度偏差 8.9e-8，保留时
  1.2e-7，两者同量级，不存在能区分二者而又不引入误报的容差。要捕获需改为
  `double` 路径或对归一化做显式契约测试（非本仓库精度模型）。

其余历史漏点（G7/G8/G11/G12）已通过新增用例全部转为可捕获。
