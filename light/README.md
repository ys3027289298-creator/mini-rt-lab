# light

矩形面光源的软影遮罩。把光源切成 N×N 均匀网格，每个格子以其**中心**处的
余弦分配辐射权重 `w = cosθ·A_cell`（cosθ 为光源法线与格心指向着色点方向
的夹角），遮罩值 `V = 可见格子权重和 / 总权重`。替代原先"四条棱仅在中点
采样"的方案——棱中点完全漏掉光源内部，遮罩中央因此出现黑斑；网格格心
采样保证内部被覆盖（奇数 N 时正中心恰有格心）。

`make test` 跑自检。

## 网格数 N 对软影边缘宽度的影响

几何（相似三角形）：光源线度 s，遮挡物距光源 d1、距接收面 d2，则半影过渡
带宽度

    w = s · d2 / d1

与 N **无关**——N 不改变真实半影宽度，只改变过渡带的离散精度：格子边长
s/N 在接收面上的投影为 w/N，采样后的遮罩曲线是约 N 级的台阶，边缘位置量
化误差 ≤ w/N，测得过渡宽度与解析值 w 的差 ≤ 2(w/N + dx)（dx 为扫掠步长）。
N 加倍，台阶加密一倍，边缘位置误差减半。

## 解析对照值

- 无遮挡 `V = 1`，全遮挡 `V = 0`（精确）。
- 直边过光源中心：cosθ 关于中心对称，`V = 1/2`（精确，偶数 N 误差为 0）。
- 偏心直边 x0：内层积分已解析求出，
  `V_ref = I(x0)/I(a)`，`I(x) = ∫_{-a}^{x} 2h·asinh(a/√(h²+t²)) dt`，
  剩余一维积分用 2^14 点中点法则求值（测试几何下误差 < 1e-9）。
- 半影宽度 `w = s·d2/d1`（测试几何 s=1, d1=d2=5 → w=1）。

## 差值上限

设遮挡物轮廓在光源面上的投影曲线总长为 L，格子边长 Δ = s/N。被轮廓穿过
的格子数 ≤ 4L/Δ + 8，于是

    |V_N − V| ≤ 2(S + E) / W
    S = cos_max · Δ · s                          轮廓两侧一格宽条带的权重上界
    E = A·Δ²·(max|f_xx| + max|f_yy|) / 24        中点法则的光滑项误差，f = cosθ
    W = 总权重

等权（cos≈1）时退化为 `|V_N − V| ≤ 4L/(sN) + 8/N² + O(N⁻²) = O(1/N)`。
竖直直边更紧：每行至多穿过一格，`|V_N − V| ≤ 1/N`（等权）。
自检中 `edge_err8`/`edge_err32` 与对应 `edge_bound8`/`edge_bound32` 会打印
出来，误差必须落在界内，且界按 O(1/N) 收缩。

## 退化处理（显式分支，不除零）

- 面积为零（`hx·hy = 0`）或 `N < 1`：退化为点光源——从光源中心投一条阴影
  光线，返回硬阴影 0/1。
- 所有格子背向（权重和为 0）：定义 `V = 0`。
- 着色点与光源中心重合（方向长度 0）：返回 0。
