# noise

按局部邻域估计每像素噪声（每像素均值的方差），输出噪声图、与真实方差比对并给出偏差上界，同时把分配结果交给自适应采样。`make test` 跑自检。

## 方法

单像素看不到自己的方差，只能从邻域里相邻像素的差异反推。

**三阶差分。** 行内取连续四像素：

```
T = m[x] - 3m[x+1] + 3m[x+2] - m[x+3]
```

任何线性或二次信号下 `T ≡ 0`，所以平滑图像里 `T` 只剩噪声。独立噪声方差为 `s2` 时

```
Var(T) = (1+9+9+1) s2 = 20 s2
```

把窗口切成互不重叠的四元组，`S = ΣT²`，则 `S/(20 s2) ~ χ²(n)`，`est = S/(20n)` 无偏。竖方向再做一遍，得到独立的第二组估计。

**偏差上界。** 因 `S/20` 的方差为 `2n·s2²`，每个方向的估计标准误为 `sqrt(2·est²/n)`；两个方向取平均后

```
se = 0.5·sqrt(2·estH²/nH + 2·estV²/nV),    bound = z·se
```

`z = 3` 时，在 Gaussian 噪声、信号局部三次以下的前提下，单像素给出约 99% 的保守保证。窗口越小四元组越少，上界随之变宽——这是方差估计应有的诚实行为。

**估计目标。** 估计量是带权窗口平均（四元组权重 1,9,9,1），不是中心像素，也不是方块平均。自检用同一个带权真值比对，否则噪声在窗口内变化时会系统性失配。

**不可估。** 邻域被图像边界裁切或半径过小、任一方向四元组少于 `MIN_QUAD`（默认 10）时，噪声与曲率无法分开：该像素标记为不可估、不给上界、分配时取平均权重，而不是硬给一个撑不住的值。默认窗 13×13，此时中心可估、角点不可估。

**自适应分配。** 采样数正比于估计方差：`var/N` 是残差，`N ∝ var` 让全图残差趋于一致。不可估像素用平均权重，以免被饿死。

## 自检覆盖

| 检查 | 内容 |
|---|---|
| `coverage_at_least_90` / `const_coverage` | 常值场景 6 次独立实现，`z=3` 上界的实际覆盖率（实测 0.975） |
| `unbiased` | 估计均值与真实方差一致 |
| `bound_shrinks_with_window` | 窗口变大四元组变多，上界应明显收窄 |
| `smooth_*` | 平滑信号下三阶差分吃掉曲率，估计仍接近真值、覆盖不塌 |
| `tiny_window_not_estimable` / `radius2_not_estimable` | 邻域过小时全部不可估，且不给上界 |
| `corner_window_not_estimable` / `interior_window_estimable` | 被裁切的角窗不可估，同等半径的内部窗可估 |
| `tiny_image_not_estimable` | 7×7 小图所有窗口都被裁切，全图不可估 |
| `graded_corr` | 多通道渐变噪声，噪声图与带权真值的相关系数（实测 ≈0.98） |
| `alloc_in_range` / `alloc_monotone_in_map` | 分配在 `[min,max]` 内且随噪声图单调 |
| `alloc_evens_out_truth` | 按图分配后真值本身的离散度大幅下降（CV 0.283 → 0.093） |
| `alloc_flattens_residual` | 端到端：按图分配后重渲染再估，残差比统一分配平坦（CV 0.109） |

运行 `./noise` 会打印分配前后的两张噪声图（固定同一色阶，`?` 为不可估）。
