# progressive

分块（tile）渐进渲染器，支持随时中止、检查点保存与续算。`make test` 跑自检。

## 设计

- **纯函数着色**：`shade_pixel(x, y, w, h)` 只用像素坐标，采样按像素哈希播种，
  无跨像素可变状态。任何渲染顺序、中断、续算都产生相同像素。
- **块是最小调度与持久化单位**：`render_step` 只在块边界检查 `abort_request`，
  一个块要么完整渲染、要么没开始，不存在半成品块。
- **检查点**：`job_save` / `job_load` 持久化 7 个 uint32 头（魔数/版本/尺寸/
  块尺寸/块数）、完成位图和 RGBA8 帧缓冲；加载时校验魔数、块数、位图取值并
  拒绝截断或带尾部垃圾的文件。续算跳过已完成块，结果与一次性行主序渲染
  逐字节一致（测试用 `memcmp` 验证）。
- **参数校验**：`job_init` 拒绝零或负的块大小与图像尺寸。
- **进度查询**：`job_progress` 返回已完成块数、总块数、块网格和完成比例。

## 接口

| 函数 | 作用 |
|---|---|
| `job_init(j,w,h,tw,th)` | 建任务；块大小 <= 0 返回 -1 |
| `render_step(j,max)` | 按确定块序最多渲染 max 个未完成块，遇中止标志在块边界停下 |
| `render_tile(j,t)` | 渲染单块；已完成则跳过（幂等） |
| `job_progress(j)` | 查询块进度 |
| `job_save/job_load` | 检查点读写 |
| `job_is_complete` | 是否全部完成 |
