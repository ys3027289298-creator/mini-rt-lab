# hdr

HDR 编码误差模型。给定指数位宽 `E`、尾数位宽 `M`，推导相对误差上界，验证误差随量级呈阶梯结构，
给出溢出/下溢的具体数值，并报告 `E=0` 时无法编码非零值。

`make test` 跑自检，输出 `key=value` 行，`all_ok=1` 表示全部通过。

## 模型

归一化值 `v = s · 1.f · 2^k`，`2^k ≤ |v| < 2^(k+1)`。每个 binade 是步长
`ulp(k) = 2^(k-M)` 的均匀网格，存入时按就近偶数舍入到网格：

```
|err|     ≤ ulp(k)/2 = 2^(k-M-1)              绝对误差，逐 binade
|err|/|v| ≤ 2^(k-M-1) / 2^k = 2^-(M+1)        相对误差，归一化区
```

相对上界只由 `M` 决定，与 `E` 无关；`E` 只决定动态范围 `[2^emin, 2^emax]`，即阶梯的高度。
反解 `2^-(M+1) ≤ target` 得 `M ≥ -log2(target) - 1`。

绝对误差每升一个八度翻倍（阶梯），相对误差处处不超过 `2^-(M+1)`（平坦）。

两端是绝对失效，不是相对误差：

- 上溢：`|v| ≥ qmax + 2^(emax-M-1)` 舍入为无穷，`qmax = 2^emax · (2 - 2^-M)`。
- 下溢：`|v| < 2^(emin-M-1)` 舍入为零，该阈值正是最小次正规数 `2^(emin-M)` 的一半；
  恰好等于阈值时就近偶数取零。
- 次正规区网格固定为 `2^(emin-M)`，相对误差无上界（最小处可达 1），只有绝对界
  `2^(emin-M-1)` 成立。

`E = 0` 没有指数字段，只有零可编码；`encode()` 对非零值返回状态 `-2`。

## 实测（`make test` 输出节选）

推导：目标相对误差 → 最小 `M`

| target | min M | 2^-(M+1) |
|---|---|---|
| 1e-2 | 6 | 7.8e-3 |
| 1e-4 | 13 | 6.1e-5 |
| 1e-7 | 23 | 6.0e-8 |
| 1e-8 | 26 | 7.5e-9 |

阶梯（E=8, M=10），绝对误差每个 binade 翻倍，相对误差恒定：

| binade | max_abs | max_rel | 2^-(M+1) |
|---|---|---|---|
| -3 | 1.22e-4 | 4.88e-4 | 4.88e-4 |
| 0 | 9.77e-4 | 4.88e-4 | 4.88e-4 |
| 3 | 7.81e-3 | 4.88e-4 | 4.88e-4 |

各格式实测相对误差均不超过推导上界：

| 格式 | E,M | 上界 | 实测最大 | 样本 |
|---|---|---|---|---|
| e4m10 | 4,10 | 4.88e-4 | 4.33e-4 | 3341 |
| half | 5,10 | 4.88e-4 | 4.33e-4 | 7453 |
| bfloat16 | 8,7 | 3.91e-3 | 3.88e-3 | 65021 |
| float32 | 8,23 | 5.96e-8 | 5.91e-8 | 65021 |

两端具体数值：

| 格式 | 最大有限值 | 上溢阈值 | 最小正规数 | 最小次正规数 | 下溢阈值 |
|---|---|---|---|---|---|
| half (E5M10) | 65504 | 65520 | 6.1035e-5 | 5.9605e-8 | 2.9802e-8 |
| float32 (E8M23) | 3.40282347e38 | 3.40282357e38 | 1.1755e-38 | 1.4013e-45 | 7.0065e-46 |
| e4m23 (E4M23) | 255.999985 | 255.999992 | 0.015625 | 1.8626e-9 | 9.3132e-10 |

编码模型对 float32 的位模式逐位复现：约 104.6 万个抽样点 + 每个 binade 的过渡点，0 处不一致。
