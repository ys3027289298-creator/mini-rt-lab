# medium

参与介质（发射 + 吸收 + 散射）的采样与自检。`make test` 跑自检。

## 物理模型

均匀平板介质 `[0, L]`，相机光线从 `z=0` 沿 +z 进入；一束强度 `I0` 的
平行光同向传播。介质参数为吸收系数 `sa`、散射系数 `ss`、发射系数 `se`，
消光系数 `st = sa + ss`。

- **透过率**：`T(d) = exp(-st d)`
- **散射距离采样**：自由飞行距离服从 `p(t) = st T(t)`，逆 CDF 为
  `t = -ln(1-u)/st`；`t >= L` 即逃逸出平板
- **方向采样**：Henyey–Greenstein 相位函数，`g=0` 退化为各向同性
  （`1/4pi`），逆 CDF 采样散射角，配合正交基转到世界坐标
- **能量守恒**：碰撞处吸收 `sa/st`、散射 `ss/st`，两者之和恰为 1；
  光子追踪的权重只乘反照率 `ss/st`，永不增大
- **发射为零**：`se == 0` 时显式报告无发光，发射贡献恒为 0；
  `st == 0`（真空）时没有可采样的交互，直接报告光束无损穿过

## 与解析单次散射解比对

沿光线的辐射度（NEE 估计量对应的解析解）：

```
L_total = se/st * (1 - T(L))
        + I0 * ss * p_HG(1) * (1 - T(2L)) / (2 st)
        + I0 * T(L)
```

三项分别为介质发射、单次散射（光束自身透过率 `T(t)` 与观察方向透过率
`T(t)` 各贡献一个指数，合并为 `T(2t)` 的积分）、直达背景。蒙特卡洛
估计量在碰撞事件上的发射项 `se/st` 与散射项
`(ss/st) I0 T(t) p_HG(1)` 的期望恰好等于前两项，逃逸事件给出第三项。

误差上界：

- 3 倍标准误：`3 * sqrt(var / N)`
- Hoeffding 界（置信度 99%，`delta = 0.01`）：
  `epsilon = b * sqrt(ln(2/delta) / (2N))`，其中 `b` 为估计量的确定上界

分层采样下按 `N = 1024 / 4096 / 16384` 验证误差与标准误随样本数单调下降。
另用发射深度质心（光晕位置）与解析值
`1/st - L T(L)/(1-T(L))` 比对。
