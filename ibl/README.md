# ibl

环境贴图预滤波：按 mip 级对应的粗糙度做 GGX 卷积，而不只是按粗糙度糊一下。

`make test` 跑自检，会打印每级粗糙度、与逐像素参考的最大相对误差及误差上界、每级能量。

- 级 k 的粗糙度为 `k / (levels - 1)`，与实时采样同一套 GGX NDF（`alpha = roughness²`）。
- 每级 texel 用 GGX 重要性采样做等权平均，权重归一到落在半球内的有效样本，因此滤波器保能量。
- 每级结果与逐像素半球积分（128×256 乘积求积）比对，相对误差须在 `5%` 内（`src/ibl.c` 的 `kErrBound`）。
- 另有与实时逐像素 GGX 采样路径的交叉比对，同一上界。
- 每级的立体角加权平均辐亮度单调不增，且与 0 级之差在 `1e-3` 相对量内。
- 恒定环境经各级滤波后保持恒定。
- mip 级数为零、级号越界、粗糙度超出 `[0,1]` 时打印具体级/数值并返回错误，不做静默 clamp。
