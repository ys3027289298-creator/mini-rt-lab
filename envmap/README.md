# envmap

等距柱状（equirectangular）环境贴图的方向查找：按球面参数化为每个纹素
预建三维方向 LUT，支持绕 +Y 的偏航旋转，并提供极点/接缝安全的反查。

`make test` 跑自检。

## 约定

y-up 右手系，纹素中心（不会正好落在极点上）：

```
u = (i + 0.5) / W,  v = (j + 0.5) / H
phi = 2*pi*u,       theta = pi*v
d0  = (sin theta cos phi, cos theta, sin theta sin phi)
```

存储方向为 `d0` 经 `R_y(yaw)` 旋转后的结果；`env_pixel` 先反向旋转再
参数化，因此贴图旋转与查询方向旋转保持一致。

## 极点与接缝

- 纹素中心取 `i+0.5 / j+0.5`，最外两行与极点相差 `pi/(2H)`，水平分量
  非零，极点处采样不退化；建表后统一归一化。
- 精确极点（水平分量小于阈值）走专用分支：经度未定义，固定第 0 列，
  行钉在极行，不调用 `atan2(0,0)`。
- `env_dir` 列按模 `W` 回绕（支持 `-1`、`W` 等越界邻居），行在极点钳制。
- 反查把 `atan2` 的 `[-pi, pi]` 平移到 `[0, 2pi)`，接缝处的浮点越界
  钳回第 0 列。
- 零/近零方向向量返回 `-1`。

## 误差上界

- 正向（LUT 方向 vs double 精度解析方向）：整球逐纹素角度误差 `< 1e-6`。
- 反查：一个纹素单元张角为 `dtheta = pi/H`、`dphi = 2*pi/W`，单位球面
  度量 `ds^2 = dtheta^2 + sin^2 theta dphi^2 <= dtheta^2 + dphi^2`，故
  单元内任一点到其中心的角度误差上界为
  `B = sqrt((pi/2H)^2 + (pi/W)^2)`，3000 个随机方向逐一验证。
- 纹素中心方向必须精确反查回原纹素。

## 非法分辨率

`W`、`H` 任一小于 2（单行无法覆盖两个极点、单列无法表达方位接缝）或
超出固定表容量（256×128）时，`env_build` 返回 `-1`，不建表。
