# mini-rt-lab

软件光线追踪基础模块，C 实现，每目录独立构建可自测。

| 目录 | 内容 |
|---|---|
| `bvh/` | 包围盒树构建、中位数分裂、最近命中 |
| `sample/` | 分层与低差异采样、方差估计 |
| `material/` | Lambert 与 GGX 求值、余弦加权采样 |
| `pipeline/` | 五阶段管线（求交/着色/累积/降噪/色调映射），每级支持直通模式，`-DENERGY_BUGS` 复现归一化缺陷 |
| `tools/` | 纯标准库分析器：PFM 独立量测、1% 落差定位、SVG/PNG 亮度曲线与 HTML 报告 |
