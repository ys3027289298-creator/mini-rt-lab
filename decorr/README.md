# decorr

同一低差异序列（2D Halton，base 2/3）被所有像素复用时，相邻像素的误差
完全相同 → 图像出现相干花纹（实测相邻像素误差相关系数 r = 1.0000）。
本模块按像素坐标派生**独立的随机化参数**，把这种相干噪声打散为近似白噪声。

`make test` 跑自检（越界参数的报错走 stderr，其余指标走 stdout）。

## 两种随机化

对像素 p 的第 i 个样本点 (u_i, v_i)：

1. **Cranley-Patterson 旋转**：`u' = (u + ξ_p) mod 1`，`v' = (v + η_p) mod 1`，
   `(ξ_p, η_p) ~ U[0,1)²`。环面平移保持积分为期望，因此单帧即无偏。
2. **索引置换**：每维一个独立的均匀 S_n 置换 `π_u,p, π_v,p`（Fisher-Yates），
   样本 i 变成 `(u_{πu(i)}, v_{πv(i)})`。

所有随机量都由 `(seed, x, y, channel)` 的 keyed hash（splitmix64 混合）确定，
无 RNG 状态、无时间/计数器依赖，**固定 seed 结果逐字节可复现**。

实现中两个关键设计点：

- 两维共用一个置换只是重排同一组 2D 点，任何函数对点集的平均值与顺序无关，
  输出完全不变；必须两维**独立**置换才能打破配对（与 Owen scrambling 同思路）。
- 置换不改变每维的边际点集，边际求积偏差在所有置换下都保留（见下）。

## 理论上界：总体相关系数 ρ = 0

像素 p 的估计量可写为其随机化参数的函数 `Z_p = g(θ_p)`，其中
`θ_p = (ξ_p, η_p, π_u,p, π_v,p)`。不同像素的 θ 由独立 hash 通道派生，
相互独立；独立随机变量的函数相互独立，因此 `Z_p ⊥ Z_q`，从而

```
Cov(Z_p, Z_q) = 0,   ρ(Z_p, Z_q) = 0
```

这就是相邻像素相关系数的**理论上界 0**。前提是参数确实独立——置换单独使用时
不满足这个前提的完整形式，因为它保留了所有像素共享的边际确定性分量。

## 有限样本上界：实测 r 不得超过的阈值

有限图像上只能算样本 Pearson 相关 r。取 M 个**互不相交**的相邻像素对
`(0,1),(2,3),…`（不相交保证各对独立；重叠对共享像素，方差公式失效）。
H0（ρ=0）下 E[r]=0、Var(r) ≈ 1/(M−1)，于是：

- 分布无关（Chebyshev）：`P(|r| > t) ≤ 1/(t²(M−1))`，
  显著性 α 的阈值 `t_α = 1/√(α(M−1))`；
- 正态近似：r ~ N(0, 1/(M−1))，3σ 阈值 `3/√(M−1)`。

自检用 64×32 图像，M=1024：Chebyshev(α=0.01) 阈值 **0.3127**，
3σ 阈值 **0.0938**。

## 实测数据（seed 固定，N=24 样本/像素）

| 模式 | 平均偏差 | RMSE | r_h | r_v | 低频能量占比 |
|---|---|---|---|---|---|
| none（同序列） | 7.26e-03 | 3.01e-02 | **1.0000** | 1.0000 | 0.63384 |
| cp | 7.28e-06 | 1.35e-02 | 0.0308 | 0.0536 | **0.00092** |
| perm | 3.95e-03 | 3.19e-02 | 0.8512 | 0.8522 | 0.53280 |
| cp+perm | -5.31e-04 | 1.53e-02 | **0.0372** | 0.0675 | 0.00478 |
| 白噪声参考值 | — | — | 0 | 0 | 0.00439 |

花纹指标取误差场 DFT 的 3×3 最低频带能量占比（Parseval 下只算 9 个系数），
白噪声的期望值为 9/像素数 = 0.00439：

- 相关系数：1.0000 → 0.0372（cp+perm），所有含 CP 的模式均低于两个理论阈值；
- 花纹指标：0.63384 → 0.00092（cp，约 690 倍）/ 0.00478（组合，约 133 倍），
  组合模式落到白噪声地板的 3 倍以内；
- 32 个独立 seed 的重复试验：cp 平均 |r|=0.0294、cp+perm 0.0277，
  Chebyshev(5%) 阈值 0.1398 违反 0 次，3σ 违反 1/32 与 0/32
  （正态近似下 32 次试验的期望违反约 0.09 次）。

### 为什么 perm 单独使用只有部分效果

置换只重排固定点集，每维边际上的 N 个 Halton 值原封不动，而 Halton 的
低频求积偏差主要由边际决定。于是估计量里残留一个所有像素共享的确定性分量，
r 仍有 0.85。64 个独立置换图像的系综平均偏差 4.04e-03，与单帧 3.95e-03
几乎相同——**边际偏差无法靠置换系综平均消除**；对照之下 CP 图像系综平均
偏差 1.94e-06（旋转会移动边际点，单帧即无偏）。组合使用时旋转把共享分量
一并打破，才达到完整去相关。

## 可复现性与越界处理

- 同一可执行文件连跑两次，stdout 逐字节一致；gcc -O0/-O3、clang 输出一致。
- 越界参数**只报错不平滑钳制**，自检向 `validate` 喂 5 组合法/非法配置，
  非法值分别打印，例如：
  `param_error: n=300 out of range [2,256]`
  （width ∈ [1,96]、height ∈ [1,96]、n ∈ [2,256]、mode ∈ [0,3]）
- hash 均匀性：16000 个 CP 偏移落 16 桶，χ²=18.60 < χ²(15, 0.99)=30.58。
