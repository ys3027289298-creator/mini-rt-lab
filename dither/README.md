# dither

8 位输出量化误差分析：直接舍入 vs 有序抖动（Bayer 8×8）vs 误差扩散（Floyd–Steinberg）。
`make test` 跑自检，输出全部实测数据与理论判定。

## 理论（q = 1 LSB）

**直接舍入** `y = round(x)`
- 误差上界：|e| ≤ q/2
- 误差是信号的确定性锯齿，缓变区形成低频平坦段 → 色带
- 锯齿在斜坡上均匀分布 → 方差 q²/12

**有序抖动** `y = Q(x + t)`，t ∈ [−q/2, q/2) 为 Bayer 阈值
- e = [Q(x+t) − (x+t)] + t，两项各 ≤ q/2 → **|e| ≤ q**
- 给定小数部分 f，误差二值分布 {−f, 1−f}：零均值，方差 f(1−f)，平均 q²/6
- 频谱：白噪声底 + Bayer 图案频率处的高频音调
- 注意：Bayer 矩阵单行的阈值不覆盖全区间（本矩阵行最大阈值仅 0.16~0.49），
  浅梯度上部分行会出现 16~24 px 的平坦段 —— 有序抖动残留色带的来源

**误差扩散** 舍弃量 e_i = u_i − Q(u_i) 前推，u_i = x_i + Σ w_k·e_{i−k}
- 逐像素：y_i − x_i = Σ w_k·e_{i−k} − e_i → **|e| ≤ (q/2)(1 + Σ|w_k|)**，
  FS 核 Σ|w| = 1 → 上界 q
- 守恒性：Σ(y−x) = (Σw_k − 1)·Σe_i − 缓冲余项。
  **Σw_k = 1 时累积误差有界（DC 均值 ≈ 0）；Σw_k ≠ 1 时 DC 泄漏、误差漂移，
  程序会打印 warning 并以 `kernel_*_sum_ok=0` 报告**
- 噪声整形：Y(z) = X(z) + E(z)(W(z) − 1)，Σw_k = 1 时 DC 处噪声传递为零，
  量化噪声被推向高频（蓝噪声）

## 实测（256×256 斜坡，100 → 108，8 个色带）

| 指标 | 舍入 | 有序 | 扩散 |
|---|---|---|---|
| max\|e\|（上界） | 0.498 (0.5) | 0.992 (1.0) | 0.976 (1.0) |
| RMSE | 0.289 | 0.408 | 0.400 |
| 方差 | 0.0833 ≈ q²/12 | 0.1663 ≈ q²/6 | 0.160 |
| 色带像素（平坦段 ≥16px） | 64096 | 27628 | 12176 |
| 低频功率占比 | 0.763 | 0.033 | 0.037 |

- 三种方法实测 max|e| 均不超过理论上界（`bound_*_ok=1`）
- 色带像素：有序 −56.9%，误差扩散 −81.0%
- 误差扩散 DC 均值 9.2e−5 ≈ 0（Σw=1 守恒）；权重和改为 0.95 时漂移被检出

色带像素定义：水平平坦段长度 ≥ 16 px 的像素（Bayer 周期 8，留一倍余量，
长于该长度的平坦段不可能是抖动微结构）。
