# lens

Brown-Conrady 径向+切向畸变的正模型与牛顿反解，含收敛阶、单调区间、
解析反解比对、可辨识性与未收敛像素统计。`make test` 自测。

## 模型

归一化像平面坐标 (x, y)，r² = x²+y²：

```
rad = 1 + k1 r² + k2 r⁴ + k3 r⁶
xd = x·rad + 2 p1 x y + p2 (r² + 2x²)
yd = y·rad + p1 (r² + 2y²) + 2 p2 x y
```

## 反解（牛顿迭代）

给定 (xd, yd)，以恒等映射为初值解 F(x,y) = distort(x,y) − (xd,yd) = 0，
2×2 雅可比解析给出（对称）。判据：‖F‖ < 1e-12，或 det J 近零 / 发散即失败。

- **收敛阶**：单调区间内 J 非奇异，实测 q ≈ 2.0（对 log|e_{n+1}| ~ q·log|e_n|
  最小二乘，剔除进入舍入区的点对）；在单调区间边界 r* 处 J 奇异，退化为线性。
- **单调区间**：径向映射 g(r) = r(1+k1 r²+k2 r⁴+k3 r⁶) 可逆 ⟺
  g′(r) = 1 + 3k1 s + 5k2 s² + 7k3 s³ > 0（s = r²）。最小正根 s* 给出
  单调区间 [0, √s*]，由三次方程解析求根。

## 解析反解比对与误差上界

仅径向 k1 时 rd = r + k1 r³ 为三次方程，Cardano 闭式求解（判别式 < 0 时
取三角形式、选单调支上的根）。牛顿结果与其比对，后验误差上界：

```
|r̂ − r*| ≤ ‖F(r̂)‖ / min g′    （区间 [0, r] 上 g′ 单调时取端点值）
```

实测 max_err ≈ 1e-14，上界 ≈ 4e-14，逐点满足。

## 可辨识性

畸变关于系数 (k1,k2,k3,p1,p2) 是**线性**的，观测雅可比与系数取值无关，
只依赖采样构型。对 JᵀJ 做特征分解，近零特征值（< 1e-10·λmax）的特征向量
支撑集即不可辨识系数组：

| 采样构型 | 不可辨识组 | 零空间维数 |
|---|---|---|
| 单半径圆环 | {k1,k2,k3}（仅组合 k1 r²+k2 r⁴+k3 r⁶ 可观） | 2 |
| 单点 | {k1,k2,k3}（2 方程 5 未知） | 3 |
| 小视场（rmax=0.02） | {k2,k3}（r⁴、r⁶ 低于数值分辨） | 2 |
| 满视场网格 | 无 | 0 |

## 未收敛像素

1280×960、f=700 扫描：广角组 (k1=−0.5, k2=0.1) 单调区间仅 [0, 1.0]，
畸变半径超过 g(r*)=0.6 的像素无单调支解，牛顿发散或落到折叠支
（计入失败），未收敛 674588 / 1228800；常规组单调无界，全部收敛。
