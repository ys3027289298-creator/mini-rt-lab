# compensate

低概率亮事件的**逆概率补偿**：按 1/q 补偿、给补偿后方差、与不补偿对照，并在补偿因子
无界时截断且把偏差来源算清楚。`make test` 跑自检。

## 模型

把定义域分成 K 个格子。格子 i 的面积占比为 `p_i`（自然/面积采样器的参考测度），
携带辐射亮度 `f_i`。目标是

    I = sum_i p_i f_i

自然采样每次取到 f_i，单样本方差

    Var_nat = sum_i p_i f_i^2 - I^2 。

一个面积很小、亮度极大的格子（p 小、f 大）让 `p_i f_i^2` 爆掉——这就是“低概率亮事件
让方差爆炸”。

## 补偿后的估计量与方差

改为从提议分布 q 抽样，每个样本乘逆概率权重 `w_i = p_i / q_i`：

    X_i = (p_i / q_i) f_i

对任意 q（只要 p_i f_i > 0 处 q_i > 0）都有

    E_q[X] = sum_i q_i (p_i/q_i) f_i = sum_i p_i f_i = I

所以**补偿后对任何提议都无偏**。方差由 E[X²] 精确给出：

    Var_q[X] = sum_i p_i^2 f_i^2 / q_i - I^2 。

- 当 `q_i ∝ p_i f_i`（能量提议）时 `w_i f_i = I`，方差为 0，每个样本都恰好返回 I。
- 若把权重丢掉、直接平均 f_i（“不补偿”），均值变成 `sum q_i f_i ≠ I`，是有偏的。

自检里把自然、能量、以及二者按 λ 混合的提议逐一算精确均值/方差，验证：

- 补偿估计在所有提议下无偏；不补偿在同一条 q 下有偏（能量提议下相对偏差 906 倍）。
- 混合 λ=0→1，方差单调下降：261856 → 796.9 → 256.3 → 76.95 → 0（相对自然下降
  99.70% / 99.90% / 99.97% / 100%）。
- 闭式方差 `sum p²f²/q − I²` 与逐点精确矩逐位相符。

## 提议分布错了（“坏 pilot”）

若用一次测量的能量估计 g 构造 `q ∝ p g`，而 g 把亮格子的能量低估 2^k 倍，则亮格子的
`w = p/q ≈ 2^k` 无界增长、方差暴涨（k=30 时 w≈65472，Var≈1.7e10，而自然采样
Var≈2.6e5）。此时：

- 补偿估计**仍然无偏**（精确和验证）。
- 不补偿的估计有偏且偏差随误估变化（k=1 时偏差 14548，k=16 时 −12）。
- 在 20 万样本下亮格子期望命中数 < 1：无偏，但实际样本里根本看不到它。

自检对 k=1..30 打印 `comp_var / nat_var`、`comp_var / raw_var`、两者偏差，并断言
pilot 尚好（k≤8）时补偿的 MSE 全面占优；pilot 差到一定程度后不加权反而方差更低——
但那是有偏估计，自检会把交叉点打印出来而不是当成优点。

## 截断无界权重，并把偏差算清楚

`w_i = p_i/q_i` 在 `q_i→0` 时无界。把权重截断在 W：

    X_i = min(w_i, W) f_i

得到的是**另一个量**的无偏估计：

    E[X_trunc] = I - sum_{w_i > W} p_i f_i (1 - W/w_i) = I - lost(W)

偏差恰好等于被截掉事件的能量 `lost(W)`。自检：

- 对每个 W 断言 `(mean − I) + lost == 0`（相对误差 ≤ 1e-9），即偏差可被解析地精确偿还。
- k=30 坏 pilot 下扫描 W=1,4,16,…,1024：W 越小方差越小、但偏差越大（W=1 时
  94% 的 I 被截掉，Var 4.0，MSE 260）；打印每个被截格子的 p、f、w 及其 lost 占比，
  **指出偏差全部来自亮格子**。W 超过最大权重（> I/f）后估计恢复精确、nclip=0。
- 能量提议下截断 W=16 会截到 63 个暗格子，`lost=0.0587`，同样满足偏差恒等式。

## 说明

- 除标注的两处 Monte Carlo 抽查外，所有均值/方差是对离散分布的精确求和，不是
  随机重复；因此“无偏”是按期望精确验证，不是统计上近似。
- 截断能压低 MSE，但用 MSE 给有偏估计背书是陷阱：W=1 时 MSE 比自然采样还小，
  可它丢掉了 94% 的积分。自检同时打印偏差与 MSE，并在注释里点明这一点。
