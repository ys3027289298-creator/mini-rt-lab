# split

`make test` 跑自检；输出带 `#` 前缀的行是数据，其余是检查项。

## 做什么

高光处样本稀疏的根因是**小光源 + 紧叶瓣**：一次 GGX 采样能否命中光源近乎是命中/未命中，绝大多数根返回 0，少数返回 ~Le。方差几乎全部集中在**半影带**——叶瓣只有一部分压在光源上、命中概率严格介于 0 与 1 之间。

本模块在该处做空间分裂：

- **粗糙度门控**：`sigma(p) <= SIG_GATE`。
- **命中位置门控**：在命中点 p，把镜面反射方向与光源中心方向的夹角，用 `alpha + light_cone`（`alpha = sigma^2`，`light_cone = asin(R/d)`）归一化，落在 `[GATE_RLO, GATE_C)` 才分裂。半影带即 `r ≈ 1` 附近。

两条门都满足才分裂，子路径复制 `K` 份、权重 `1/K`，因此 `E[Y | root] = E[X | root]` 对所有 `K` 成立。`K = 1` 时不评估任何门、不消耗额外随机流，逐样本退化为原路径。

子路径采用**分层**：`K` 个子路径各自只在自己那一块 VNDF 采样域子矩形内抖动，因此半影边界在每个分裂根内部就被解析，而不是靠运气。IID 子路径也一并测量作对照——由于门控已经筛掉了高方差根，IID 在等预算下也能赢，分层是在此之上的额外收益。

## 预算口径

基线根 2 条光线（primary + shadow），分裂根 `1 + K` 条。等总光线预算下根数按 `2 / cost` 缩放，故

```
eq = (Var[Y] / Var[X]) * (cost / 2)      gain = 1 / eq
```

`eq < 1` 即等总样本下分裂获胜。

## 默认场景实测（`make test`）

`N = 400000` 根，`DECOMP` 行显示 within-root 方差占 58.3%，门控只命中 0.79% 的根却捕获其中 94.1% 的 within 方差：

| 子路径 | K | 相对成本 | eq | gain |
|---|---|---|---|---|
| strat | 2 | 1.004 | 0.737 | **1.36×** |
| strat | 4 | 1.012 | 0.588 | **1.70×** |
| strat | 8 | 1.029 | 0.540 | **1.85×** |
| strat | 16 | 1.062 | 0.505 | **1.98×** |
| iid | 4 | 1.012 | 0.624 | 1.60× |

所有 K 的 `t_bias` 均 < 1，配对检验 `unbiased_all_k=1`；`mismatch` 只出现在被分裂的根上（`only_split_roots_change=1`）。

## 可调参数

编译期宏覆盖，例如：

```
gcc -O2 -std=c11 -DSIG_GATE=0.25 -DGATE_C=4.0 -DIMAGE_HW=0.20 src/splitting.c -o splitting -lm
```

| 宏 | 含义 | 默认 |
|---|---|---|
| `SIG_GATE` | 粗糙度上限 | 0.35 |
| `GATE_C` / `GATE_RLO` | 位置门带 `[RLO, C)` | 3.0 / 0.0 |
| `IMAGE_CX/CY/HW` | 采样足迹中心与半宽 | 0.12/0.08/0.30 |
| `LIGHT_R` | 光源半径 | 0.015 |
| `N_ROOTS` | 每轮根数 | 400000 |

注意：门控收益依赖于场景落在“半影带宽 ≈ 像素足迹”这一档；可把 `GATE_RLO` 设为 `1.0` 附近只分裂半影外侧，或放宽 `GATE_C` 包住整个亮斑，后者会更贵、收益也更低（见 README 顶部的预算公式）。
