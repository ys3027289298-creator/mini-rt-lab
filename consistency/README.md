# consistency

光栅化器与光线追踪器的逐像素一致性校验。两套渲染器吃同一份场景、同一套
相机和着色公式，输出同格式帧缓冲；Python 侧逐像素比对、按差异根因分类，
并与人工标注集核对，最后断言结论随分辨率变化保持稳定。

## 目录

| 路径 | 作用 |
|---|---|
| `src/common.h` | 场景解析、相机/着色公共代码、帧缓冲 IO |
| `src/raster.c` | float32 光栅化器：边函数填充、透视校正插值、线性深度测试 |
| `src/tracer.c` | float64 光线追踪器：每像素一条主光线、Möller–Trumbore 最近命中 |
| `tools/consist_check/` | 帧缓冲读取、差异分类器、人工标签 recall |
| `tools/run_check.py` | 端到端入口：多分辨率渲染、分类、标注核对、稳定性断言、报告 |
| `tools/labeltool.py` | 人工标注辅助：按类打印候选像素与诊断量 |
| `tools/diag_*.py` | 阈值/尺度/颜色差的探查脚本 |
| `scenes/` | `clean.scene`（精度基准）、`lab.scene`（三类差异压力场景） |
| `labels/lab_labels.json` | 人工标注集（点 + ROI，含溯源） |

## 运行

```sh
make test
```

产物在 `out/`：每分辨率两份 `.fbuf`、一张差异叠加 `_diff.png`、汇总
`report.json`。退出码 0 表示全部闸门通过。

## 帧缓冲格式

两个渲染器输出完全一致的二进制：4 个 uint32 头（magic、宽、高、通道数=5），
随后是 `width*height*5` 个 float32，每像素为
`[r, g, b, linear_view_depth, primitive_id]`，背景为深度 `1e30`、id `-1`。

## 差异分类（互斥，依据几何而非任意数值阈值）

- **precision（精度）**：两帧命中同一图元（id 相同），仅颜色/深度数值不同。
  来源是光栅化 float32 边函数/插值路径 vs 追踪器 float64 求交。随面积
  ~ O(s²) 增长。
- **boundary（边界）**：两帧选中不同 id，且两个争议 id 在该像素 3×3 邻域内
  共存——共享边/轮廓上的一像素归属之争。随边长 ~ O(s) 增长。
- **occlusion（遮挡）**：两帧选中不同 id，但争议 id 在局部不共存——深度面
  交叉导致可见性在内部带状区翻转，而非沿几何边。随面积 ~ O(s²) 增长。
- **unclassified**：匹配不到任何规则的差异像素。出现即判失败，强制分类法
  必须覆盖两种实现能产生的全部分歧。

容差（`COLOR_EPS`、`DEPTH_REL_EPS`）只用于把 float32 量化底噪（约 1e-6）
排除出"差异"，不参与类别划分，因此与分辨率无关。

## 人工标注与零漏分类闸门

`labels/lab_labels.json` 是在 320×240 下人工核验、并在 160×120 与 640×480
复验的真值集，含点标签和 ROI 标签（边界线在整数重网格下会整列抖动，故用
矩形 ROI 标注）。每个标签都必须被自动分类器以相同类别命中，否则记一次
miss；闸门要求各分辨率下 miss 数为 0。

## 尺度稳定性闸门

同一视场在 160/320/640 宽度下渲染，要求：

1. 出现的类别集合在各分辨率完全一致；
2. 每类像素数随尺度的幂律指数落在 `[0.5, 2.5]`（边缘 O(s)、面积 O(s²)）；
3. 占比最大的类别在各分辨率保持不变。

实测指数（lab 场景）：occlusion ≈ 2.04、precision ≈ 1.99、boundary ≈ 0.62。

## 设计要点 / 已排除的误区

- 两个渲染器都做**双面渲染**并把着色法线统一朝向相机，否则平面三角形会
  因法线符号相反产生系统性亮度差。
- 孤立三角形（含细条带）的**轮廓在两渲染器间不会产生分歧**：两者都对同一
  像素中心、用同一几何做判定。边界类差异只可能来自交叠图元的深度交叉带
  边缘，lab 场景据此用窄交叉条带构造。
- 共面、亚 float32-ULP 的深度差在两条管线里结论一致，不产生遮挡分歧；
  真正的遮挡差异需要不同斜率的深度面在投影内部交叉。
