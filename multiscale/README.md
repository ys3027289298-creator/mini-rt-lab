# multiscale

远处物体偏暗、颜色不一致的多尺度修正：按距离调整采样密度、按像素覆盖率加权，
把结果覆盖归一化后与近距离渲染比对，并用解析模型给误差上界。

- 解析模型：`Ω(d) = area·cosθ/d²`，覆盖率 `c = clamp(Ω/pixel_sa, 0, 1)`；
  像素积分亮度 `L·c` 随距离下降是正确行为，发光体自身的辐射亮度 `L` 才是尺度无关量。
- `ms_render_pixel` 覆盖归一化后在各距离都还原 `L`，与近距离（`c` 被夹到 1）渲染一致。
- `ms_budget` 令 `n = clamp(target/c, min, max)`，覆盖率下降时采样密度上升。
- `ms_error_bound` 给出逐通道误差上界（相对解析亮度）：覆盖模式为浮点误差量级，
  点采样模式按二项分布取 `z·sqrt((1-c)/(c·n))` 的 z 倍标准误差（每像素统计上界，
  对 K 个独立像素平均可收紧 `sqrt(K)` 倍）。
- 所有接受距离的入口对 `d <= 0`（及 NaN/Inf）返回 `MS_ERR_DISTANCE`，不写出结果。

`make test` 跑自检。
