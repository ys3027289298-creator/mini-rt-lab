# upsample

低分辨率渲染结果的边缘引导上采样，`make test` 跑自检。

## 功能

- `upscale_edge`：中心差分检测源图边缘；边缘像素沿边缘方向做一维插值
  （避免横跨边缘的模糊），非边缘区域走双线性，按边缘强度 `w` 混合。
  `sharp > 0` 时叠加 unsharp 锐化项 `sharp * (edge - bilinear)`。
- `upscale_bilinear` / `upscale_nearest`：对照基线；最近邻复制到全分辨率
  网格，作为“放大前”误差的测量对象。
- `box_downsample`：面积加权降采样，整数倍时等于精确的盒式均值。
- `compare_img`：对同尺寸全分辨率参考图输出 MAE、RMSE、最大绝对误差
  `maxabs`（L∞ 范数）和超阈值像素数。
- `count_overshoot`：统计边缘邻域内输出值超出双线性足迹内源像素
  `[min, max]` 范围（容差 `tol`）的过冲像素数，同时报告边缘区域总像素数。

## 指标定义

- MAE = mean |输出 - 参考|，RMSE = sqrt(mean 误差²)。
- maxabs = max |输出 - 参考|：逐像素误差的保证上界，自检中独立逐像素复核。
- 放大前误差：低分辨率图按最近邻放到全分辨率网格后与参考图比较；
  放大后误差：上采样结果与同一张参考图比较，两组指标同一口径。
- 边缘过冲：仅统计源边缘像素 2×2 邻域覆盖到的输出像素。无锐化时插值
  为凸组合，过冲必为 0；锐化可能产生过冲，像素数必须如实报告。

## 缩放约束

只允许上采样：目标尺寸必须在 x、y 两个方向都严格大于源尺寸，比例 ≤ 1
（含比例正好为 1）一律返回 `UP_ERR_SCALE`；降采样不属于本模块，由
`box_downsample` 的独立尺寸检查拒绝。
