# penumbra

半影（软阴影）的**解析校验**：不靠眼看，而是用面光源面积、遮挡距离推出
半影宽度，再和蒙特卡洛"渲染"结果逐项比对并给出误差上界。`make test` 跑自检。

## 解析几何（垂直于遮挡物直边的 2D 截面）

- 面光源：矩形，面积 `A`、平行边边长 `H`，则垂直边方向宽度 `L = A / H`，半宽 `a = L/2`
- 遮挡物半宽 `b`；光源→遮挡物距离 `d_l`；遮挡物→接收面距离 `d_r`，总距离 `D = d_l + d_r`

相似三角形给出接收面上的边界：

```
本影边缘   x_u = b + (b - a) * d_r / d_l
半影外沿   x_p = b + (b + a) * d_r / d_l
半影宽度   W   = x_p - x_u = L * d_r / d_l = (A / H) * d_r / d_l
```

存在本影时归一化辐照度（光源可见比例）是分段线性剖面：

```
f(x) = 0                       |x| <= x_u   （本影）
       (|x| - x_u) / W         中间斜坡      （半影）
       1                       |x| >= x_p   （全亮）
```

实现里 `exact_f()` 用更一般的形式：反解遮挡平面映射，在**光源坐标**中求被遮挡
区间与光源区间 `[-a, a]` 的重叠长度。这一个公式同时覆盖三种几何：

| 几何 | 条件 | 剖面特征 |
|---|---|---|
| 真本影 | `x_u > 0` | 中心为 0 的本影平台 + 斜坡 + 全亮平台 |
| 切线 | `x_u = 0` | 中心恰好为 0，无本影平台 |
| 无本影 | `x_u < 0`（宽光源小遮挡物） | 中心仍有光照，剖面底部高于 0 |

## 测量方法

- 只扫描右半边 `[0, xmax]`（剖面关于 0 对称）；网格按场景**自适应**，目标
  每个解析半影宽度约 24 个格，并在半影外沿外保留 16 个全亮平台格
- 每个接收点对光源做 8192 次分层 MC 可见性采样，估计同一可见比例——与解析
  量是 apples-to-apples 比较
- 跨点电平取斜坡自身范围 `[f(0), 1]` 的 20%/80%：无本影几何底部存在平台，
  固定 0.2 电平会落在平台上使跨点定义不良
- 斜坡斜率为 `1/W`，由两个电平跨点距离除以电平跨度恢复测量宽度 `Ŵ`

## 校验项（面光源）

| 检查 | 内容 |
|---|---|
| `profile_matches_analytic` | 逐点 MC 与解析剖面误差 ≤ 4σ（Bernoulli σ = 1/(2√N)） |
| `width_within_bound` | `|Ŵ − W|` 不超过显式上界：`4√2·σ·W/Δt + 1.5h`（双跨点 4σ 噪声 + 1.5 个网格的插值括号误差） |
| `boundary_no_jump` | 相邻扫描点最大跳变 ≤ 解析单格增量 `h/W` 加噪声项，边界处无硬台阶（C0） |
| `boundary_value_continuous` | 最小二乘斜坡在本影边缘接到 0、全亮边缘接到 1（衔接误差 ≤ 4σ） |
| `boundary_kink_bounded` | 斜坡斜率与平台斜率之差（折点）与解析折点 `1/W` 一致，相对误差 ≤ 0.15 |
| `no_umbra_center_lit` / `tangent_center_matches` | 无本影/切线几何的中心值与解析值一致（≤ 4σ） |

关于"梯度连续"：直边面光源的解析解本身是**分段线性、值连续但梯度有有限折点**
（C0 而非 C1），所以这里校验的是可物理验证的结论——无跳变、折点大小与解析
斜率在采样噪声内一致，而不是要求解析上不存在的 C1 连续。

## 点光源退化（面积为零）

光源面积 `A = 0` 时 `L = W = 0`、`x_u = x_p`，半影必须消失：

| 检查 | 内容 |
|---|---|
| `zero_area_analytic_width_zero` | 解析宽度显式为零且两个边界重合 |
| `zero_area_measured_width_zero` | 测量宽度不超过一个网格间距（有限离散网格的极限） |
| `zero_area_profile_binary` | 剖面只有 0/1 两个值 |
| `point_light_hard_edge` | 相邻点出现完整 0→1 硬边跳变 |

## 健壮性

自检内置 4 个场景（真本影、无本影、切线、点光源）。开发期间另用脚本扫过
864 组几何 × RNG 种子组合（不同 `d_l`、`d_r`、光源面积、遮挡物尺寸），全部通过。
