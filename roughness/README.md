# roughness

把感知粗糙度 `r`（滑杆，0..1）映射到 GGX 微表面参数 `alpha`，让"看起来的模糊程度"与滑杆成线性关系。

`make test` 跑自检（22 项），`make plot` 出图。

## 为什么需要映射

直接把滑杆接到 `alpha` 时，模糊感不成比例：GGX 高光宽度对 `alpha` 是非线性的，
而教科书常用的 `alpha = r^2` 又会让中低粗糙度区域明显偏锐利（实测最大偏差约 20%）。

## 方法

1. **模糊度量**：取 GGX 微表面法线倾角的 cos 加权分布中位数 θ50，归一化到 0..1 得到
   模糊响应 `B(alpha)`。cos 加权（`D cosθ dω`）是微表面法线在投影面积上的概率测度，也是
   NDF 的归一化约束 `∫D cosθ dω = 1`。不用渲染图像素 σ，是因为 Smith G2 遮蔽函数会在高
   粗糙度下压暗掠射方向的长尾，使像素 σ 在中段出现峰值后回落——那是真实物理，但不是单调
   的模糊度量。θ50 对 `alpha` 严格单调。
2. **解析 CDF**：cos 加权倾角分布的累积函数是
   `P(θ) = tan²θ / (α² + tan²θ)`，
   因此分位数有闭式解 `tan²θ_q = α²q/(1−q)`，中位数就是 `θ50 = atan(α)`
   （α=1 时为 45°）。自检用 4096 点均匀 θ 网格数值积分独立交叉验证。
3. **映射构造**：在 81 点 `alpha` 扫描上求 `B`，反演到 1024 点感知网格，得到单调 LUT
   `alpha_lut(r)`（`out/mapping_lut.csv`），这是交付的主映射。
4. **紧凑近似**：另拟合幂函数 `alpha = r^p`（本机构得 p≈1.14）作对比；LUT 精度远高于它。
5. **误差上界**：LUT 节点落在精确反函数上，节点间用 Lipschitz 常数
   `L = max|dB/dalpha|` 与 `max|dalpha/dr|` 给出连续误差界
   `e_grid + L·max|dα/dr|·h/2`。实测连续上界 < 0.1%。

## 结果（本机一次运行）

| 映射 | 网格最大绝对误差 |
|---|---|
| 单调 LUT（交付） | 1.6e-5，连续上界 0.001 |
| 幂近似 α=r^1.14 | 0.049 |
| 教科书 α=r² | 0.197 |

曲线严格单调（1024 点与 4096 点密集网格均检查），`r=0 → α=0 → 完美镜像`，`r=1 → α=1`。

## r = 0 镜像导出

`out/mirror_r0.ppm`（P6，160×160）是 `alpha=0` 的纯镜面渲染：中心一个锐利太阳反射斑，
带白色边框和位图文字标注 `R=0 ALPHA=0 / MIRROR`。

## 输出文件（`out/`，运行后生成）

| 文件 | 内容 |
|---|---|
| `mapping_lut.csv` | 1024 点单调映射 `r,alpha`（主交付） |
| `mapping_curve.csv` | LUT / 幂近似 / r² 三条曲线对比 |
| `alpha_sweep.csv` | 模糊响应 B(α) 与 θ50 角度 |
| `validation.csv` | 各映射在感知网格上的实测误差 |
| `render_crosscheck.csv` | MC 渲染像素 σ 与边缘能量（G2 效应交叉验证） |
| `curves.png`, `validation.png` | 曲线图与误差图 |
| `mirror_r0.ppm` | r=0 镜像标注图 |
| `summary.txt` | 数值摘要 |

## 实现说明

- 单文件 C，GGX NDF / Smith G1,G2 / Heitz visible-normal 采样齐全；太阳方向取相机中心
  光线对地面的反射方向，保证镜面光斑落在画面中心。
- MC 渲染（240×240，196 spp 分层）仅作独立交叉验证；主度量是解析的，不依赖渲染收敛。
- 高 `alpha` 时高光物理上铺满整个地面，有限画面必然裁切，因此边缘能量检查只约束 α≤0.3
  的低粗糙度区。
