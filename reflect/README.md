# reflect

金属反射贴图的**分帧分块重算 + 时间累积**模拟，`make test` 跑自检。

## 问题模型

反射贴图每帧只重算一部分（分 tile，共 16 块；基线策略每帧重算 8 块，即
"算了一半就提交"）：

- 被刷新的 tile：本帧重新 trace，与旧值做 EMA 混合
  `map = alpha * x_new + (1-alpha) * map`（时间累积）；
- 未刷新的 tile：沿用上一帧结果，内容年龄 +1；
- 金属物体以角速度 `omega` 相对静态环境旋转，过期 texel 即表现为拖影。

## 两个独立测量量

- **滞后帧数 lag**：每个 texel 维护年龄计数器（刷新时
  `age = (1-alpha)(age+1)`，未刷新 `age+1`），全图取平均。稳态有解析解
  `lag = (1-alpha)I/alpha + (I-1)/2`，`I = T/K` 为刷新间隔，程序用它
  交叉验证实测值。
- **拖影长度 smear**：逐 tile 在候选平移上对清晰真值做最小二乘匹配
  （SSE + 抛物线亚像素细化），输出 texel 与弧度，理论上
  `smear ≈ omega * lag`。图像域里 EMA 模糊与延迟会互相混淆，所以滞后
  帧数以年龄计数器为准、不依赖图像拟合。

## 实验

三档角速度 `0.005 / 0.03 / 0.06 rad/frame`，各跑一次（预热 128 帧 +
测量 128 帧），基线输出三组共六个数（lag、smear）。最快档的平移量控制在
图像拟合可辨识范围内（过快运动下 EMA 重模糊会使延迟被低估）。

固定 1/2 分帧比例下 lag 与角速度无关（三档同为 2.5 帧），但最快档 lag
超过 `LAG_LIMIT=2` 帧即触发告警，说明分帧比例没有跟随角度变化率调整。
随后按 `omega * lag <= 0.12 rad` 的拖影预算自适应选择每帧重算块数 K
（alpha 固定 0.5），三档得到 K = 1 / 8 / 16，分帧比例与滞后帧数并列输出。
