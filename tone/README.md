# tone

可逆色调曲线：`make test` 跑自检。

- 曲线：`x[0..n-1]` 结点上的分段三次 Hermite，结点增益 `g[k]` 为局部斜率（`g=1` 为恒等），段内归一到 `f(x[i+1])-f(x[i]) = x[i+1]-x[i]`，区间外按端点切线线性延拓（C1）。
- 逆：延拓段闭式求解，内部二分到 `1e-7*(1+|x|)`。
- 单调性：解段内斜率二次式 `L(u)` 的精确极值，非单调段给出 x 区间。
- 往返误差：给出解析上界并与实测比较。
- 解析逆：对称单段族 `g[0]=g[1]=g` 的逆用 Cardano 闭式求，与数值逆比对。
- 参数校验：越界时报告字段、下标与取值。
