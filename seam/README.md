# seam

光照贴图 UV 接缝修复。`make test` 跑自检。

## 接口

```c
SeamParams p = { .seam_x = 32, .band = 5.0f, .threshold = 2e-3f, .gradient_match = 1 };
SeamReport rep;
seam_repair(&image, &p, &rep);
```

竖直接缝位于 texel 边界 `u = seam_x`（`x-1` 与 `x` 两列之间），
两侧是同一连续表面在 UV 展开中的两份拷贝。

## 流程

1. **测接缝**：每一行在接缝两侧按 0.5/1.5/2.5/3.5 texel 偏移取双线性样本，
   用三次 Lagrange 外推到 `e = 0`，得到左右两侧的边界值 `L0, R0` 与边界斜率 `L1, R1`。
   值跳变 `D = L0 - R0`，梯度跳变 `S = L1 - R1`。
2. **判定**：全局 `max|D|` 低于 `threshold` 时判定无接缝，**一个像素都不写**，直接返回。
3. **补偿**：在接缝两侧各 `band` texel 宽的带内，按带参数 Hermite 剖面
   `w(t) = h00(t) + alpha * h10(t)`，`t = e / band`，把 `-D/2` 与 `+D/2` 分给两侧。
   `h00(1) = h00'(1) = h10(1) = h10'(1) = 0`，故带边界处 `w(1) = w'(1) = 0`，
   与 `alpha` 无关；带外像素保持不变。
4. **梯度匹配**：`alpha = clamp(band * S / D, ±2*band)`。
   `alpha = 0` 只消值跳变、会把跳变转成带内拐点；匹配斜率后接缝两侧的
   值和一阶导数都对齐。`gradient_match = 0` 可关闭。
5. **验收**：修复在暂存副本上进行；独立估计器测得的值跳变若仍 `>= threshold`，
   则**整次修复合弃**、原图逐位不变（`rep.accepted = 0`）。这样"接缝残差必须低于阈值"
   成为提交前提，而不是事后报告。
6. **残差**：修复后再用**另一套**更宽、更高阶的估计器
   （0.75…4.75 texel 五点、四次外推）独立测值跳变与梯度跳变，
   避免用构造补偿的同一估计器自证。

## 误差上界

`rep.bound = residual_before + residual_after`，这是"修复后像素与精确重烘焙之差"的上界，
其依据与前提：

- 接缝只把两侧各自整体平移了 `D/2`，带外的真实辐射度不变；
- 修复后剩余的值跳变由独立估计器测得为 `residual_after`；
- 对**对称型**接缝（两侧朝相反方向漂移）且真实剖面在 `band` 内光滑可控时，
  自检中实测误差 ≤ `bound`，且远小于修复前（quad/slope/exp 提升 > 2×）；
- 对**单侧偏置**（只有一侧漂移），本方法把 `D/2` 分给两侧，值跳变被消除，
  但绝对偏移会留在两侧、`bound` 不再覆盖它——这是对称修复的固有限制。
- 盒状（box）剖面若比 `band` 还宽，光滑带无法表示；此时独立估计器的残差
  降不到阈值以下，按第 5 步整次修复合弃，输入原样保留。

注意 `bound` 覆盖的是"带外的绝对偏移 + 接缝处残余跳变"这一保守上界，
它可能明显大于带内逐像素的实际差值；它保证不漏报上界，但不是紧界。

自检覆盖：无接缝（含全图平滑起伏）零改动、四种剖面形状的检测/残差/带内唯一性/
误差上界、梯度匹配增益、二次调用幂等、确定性、亚阈值免修、倾斜光照复验、
不可表示剖面被拒且原图逐位不变。

## 限制

- 仅支持竖直接缝（`u = seam_x` 为 texel 边界），不支持横向或斜向接缝；
- 假设接缝两侧是同一连续表面；若两侧本就是不同材质/朝向，不应修复；
- 采样环最宽 4.75 texel，`band` 不得超出图像范围（接口会返回 -1）。
