# glass

大面积玻璃幕墙渲染出的规则水波纹（莫尔条纹）的复现、诊断与修复。

## 现象

幕墙渲染出来出现等间距条带，像干涉条纹。条纹的疏密只随**细分密度**
（幕墙每行玻璃板数 `D`）和**每像素采样数**（`S×S` 分层采样）变化，两者
的栅格互相拍频：采样格与玻璃板栅格锁相，每块玻璃板上的波纹在像素内被采到
**同一相位**，像素平均值沿幕墙缓慢漂移，形成低频条带。

## 机制与判据

设一块玻璃板宽 `p = W / D` 像素（`W` 为图像宽）。采样格在每个像素内位置
固定，从一像素到下一像素相对玻璃板边界前进 `frac(p)` 个板宽。由此得到
栅格采样的条带波长

```
lambda = p / frac(S*p)          每像素每轴 S 个样本
  =>   lambda * D = W / frac(S*W/D)
```

**判据**：只要三档细分的采样格相对玻璃板栅格保持相同偏移（三档的
`frac(S·W/D)` 近似相等），栅格采样就会给出近似**常数**的 `lambda · D`。
`lambda·D` 近似常数 = 采样仍被细分锁住，偏移量没有起作用。

三档由此挑选（`frac(S·p)` 分别 0.1695 / 0.1739 / 0.1687，相差 < 3%）：

| `D` | 板宽 `p`(px) | 预测 `lambda`(px) |
|---|---|---|
| 708 | 0.542 | 3.20 |
| 368 | 1.043 | 6.00 |
| 249 | 1.542 | 9.14 |

板宽从 0.54 变到 1.54 像素，预测波长翻近三倍，但乘积应保持常数。

## 修复

给每个像素的整组采样加一个**低差异（R2 序列）偏移**，索引为像素本身：同一
像素内的 16 个样本**整体**平移，像素间各不相同。

- **偏移量的取值范围由细分密度反推**：一个玻璃板周期 `p = W/D` 像素（正好
  覆盖采样要积分的图案的一个完整周期），并封顶在 1 像素——细分很密时退化为
  亚像素抖动，不把像素足迹撑大。`glass_offset_radius()` 就是它。三档都不封顶
  （0.54 / 1.04→1.0 / 1.54→1.0），密档真正用上了 `W/D` 反推的 0.54。
- **为什么整像素一起转而不是逐样本转**：逐样本偏移也能打破锁相，但会毁掉
  分层，把逐像素噪声放大约一倍（实测 0.15→0.28）。整组平移只改相位、不改
  分层间距，逐像素噪声几乎不变（0.15→0.15），同时把相干条带压掉 13–35 倍。

## 三档实验

`make test` 跑自检，再渲染三档、各用两种采样器：

```
D     pitch   frac    pred_lam grid_lam grid_lamD band_grid band_off  px_grid   px_off
708   0.5424  0.1695  3.20     3.20     2266      0.10395   0.00798   0.14738   0.15550
368   1.0435  0.1739  6.00     6.00     2208      0.10694   0.00461   0.15152   0.15159
249   1.5422  0.1687  9.14     9.14     2277      0.09414   0.00273   0.13366   0.14368

lambda*D constancy (max/min, near 1 = no effect):
  grid  : 1.031
  offset: 2.938
```

- `pred_lam = p/frac(S·p)` 与实测 `grid_lam` 逐档完全吻合，机制得到验证。
- **栅格采样**：三档 `lambda·D = 2266 / 2208 / 2277`，散布 **1.03×** —— 乘积
  近似常数，条纹确实存在且由细分密度锁相。`band_grid ≈ 0.10`，即列平均后仍
  剩 10% 的相干条带。
- **偏移采样**：`band_off = 0.008 / 0.005 / 0.003`，相干条带被压掉 13–35 倍；
  `px_off` 与 `px_grid` 基本持平（0.15），说明不是靠抹平噪声换来的。
  此时 `off_lam` 只是白噪声谱峰的落点，`lambda·D` 散布 2.9×，不再成立——这正是
  “偏移量起了作用”的对照。

（`band` = 把相对残差沿列平均后的 RMS，衡量**相干条带**；`px` = 逐像素相对残差的
RMS，衡量普通采样噪声。两者分开报告，避免把“噪声变大”误当成“条纹消失”。）

## 样本位置对照图

题面要求：若某档乘积近似常数，就把该档实际使用的采样位置画出来对照。程序为
每档导出两种采样器的**绝对**采样坐标（`out/samples_D*_*.csv`），绘图脚本把它们
和玻璃板边界叠在一起（`out/samples_D*.svg`）：

- 栅格档：每像素重复同一套格点，格点相对板边界的偏移逐像素按 `frac(p)` 漂移
  ——这就是锁相。
- 偏移档：整套格点被 R2 偏移整体打散，相对板边界的偏移逐像素翻乱，锁相破坏。

`out/stripe_D*.svg` 画每档去趋势后的列平均残差（栅格 vs 偏移，标出预测波长），
`out/summary.svg` 用 log-log 画“条纹间距 vs 细分密度”，栅格档落在 `lambda ∝ 1/D`
上，偏移档散成噪声。

## 构建与运行

```
make            # 构建 moire / selftest
make test       # 自检 + 三档实验（产物写到 out/）
make figures    # 把 out/ 的 CSV 画成 SVG（纯标准库 Python）
```

`out/` 产物：

- `summary.csv` —— 每档的预测/实测间距、`lambda·D`、band/像素 RMS、压制比
- `stripe_D*_{grid,offset}.csv`、`samples_D*_{grid,offset}.csv` —— 绘图数据
- `stripe_D*.svg`、`samples_D*.svg`、`summary.svg` —— 图

## 自检（`selftest`）防回归

- 无波纹的平滑幕墙：栅格与偏移两种采样都与精确盒式滤波一致（偏移不改变平滑
  积分的收敛值）
- 偏移半径随 `W/D` 变化、且封顶在 1 像素；偏移后样本仍在像素足迹内
- 栅格仍是规整 `S×S` 格点；相邻像素偏移不同（解耦）
- 精确参考与 2D 数值积分一致
- **核心回归**：锁相档上栅格留下条纹（三档 `lambda·D` 散布 < 1.10×），偏移把
  相干条带压到栅格的 15% 以下，且逐像素噪声不超过栅格的 1.3 倍
