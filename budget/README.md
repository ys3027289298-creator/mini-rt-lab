# budget

固定总样本预算 `B = pixels × spp` 下，分辨率与每像素样本数的权衡分析。

`make test` 跑自检（含手算 2×2 网格、空集、精确命中、16 组参数扫描）。

## 误差模型

$$E(P, s) = \frac{a}{P} + \frac{v}{s}$$

- `a/P`：P 像素图像的离散化偏差（像素越多偏差越小）；
- `v/s`：每像素 s 个样本的蒙特卡洛方差（spp 越高方差越小）；
- 成本约束：`P · s ≤ B`。

## 做了什么

1. **枚举可行组合 + 误差曲线**：在分辨率网格（8²…256²）× spp 网格（1…1024）
   上枚举，只保留 `P·s ≤ B` 的组合，输出每条误差曲线；
2. **与穷举最优比对 + 偏差上界**：
   - 穷举：对所有可行组合取 `min E`；
   - 快速选择：从连续松弛最优 `P* = √(aB/v)`、`E*_c = 2√(av/B)` 出发，
     取对数距离最近的可行分辨率，再取该分辨率下最大可行 spp；
   - **实例上界（无需任何网格假设）**：`E_pick ≥ E_exh ≥ E*_c`，故
     `E_pick − E_exh ≤ E_pick − E*_c`，逐实例可验证；
   - **结构性上界（网格条件成立时）**：当选中的 P 与 P* 相差不超过 2 倍、
     且 spp 浪费不超过一半预算时，`E_pick ≤ 2.25 · E*_c`，
     即相对穷举最优的偏差不超过 125%；
3. **空集报告**：最小成本 `P_min·s_min > B` 时返回 0 个组合、哨兵索引 -1，
   并输出 `no feasible solution`。

## 用法

```sh
make test                       # 自检
./budget report 1048576 4 1     # B=1M, a=4, v=1 的完整文本报告
./budget csv    1048576 4 1     # 机读 CSV（首行 # 元信息，含 E*_c 与角色标记）
./budget empty                  # 空集演示（B=32，最小成本 64）
make plot                       # 生成 ../artifacts/budget_{curves,bounds}.png
```

`report`/`csv` 参数均为正数：`B a v`。

## 输出文件

| 文件 | 内容 |
|---|---|
| `../artifacts/budget_curves.png` | (a) 各分辨率误差 vs spp 曲线、连续下界、最优点；(b) 每分辨率最佳误差 vs 像素数 |
| `../artifacts/budget_bounds.png` | 预算扫描：观测偏差 vs 认证上界（对数绝对偏差 + 线性相对偏差，空集区域加阴影） |

## 设计要点

- C 模块是唯一计算源；`tools/plot_budget.py` 只解析 `csv` 输出，不重算误差；
- 连续松弛最优是所有离散误差的下界，因此实例上界对**任意**网格都成立，
  结构性 2.25 倍上界只在网格间距条件满足时声明，自检会分别验证两种情形。
