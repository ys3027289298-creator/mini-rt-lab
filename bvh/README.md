# bvh

`make test` 跑自检（bvh 与 qbvh）。

- `src/bvh.c` — 宽（二叉）节点基线：构建、中位数分裂、最近命中
- `src/qbvh.c` — 量化窄节点：8 子节点定长组（128 B，遍历一次取一整组），
  子包围盒 8-bit 量化（向外取整，不丢命中）+ 4 B 压缩索引；
  自检输出压缩率、遍历代价、模拟 L1 缓存未命中对比、与宽节点命中一致性，
  并对越界索引拒绝（validate 与遍历双层防护）
