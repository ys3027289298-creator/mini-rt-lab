# viscache

软影的逐光源可见性缓存，`make test` 跑自检。

- 每个光源一份接收面网格缓存，单元格存"面积光可见比例"。
- 查表用双线性插值；命中不发射线，未命中/误差超容差才重算。
- 单元格误差按"加密一层采样后的变化量 + 量化项"估计，低于 `TOL` 停止加密。
- 每次查表给出误差上界：外圈 3×3 单元格的最大估计误差 + 该块数值跨度 + 插值截断 `h²` + 直接参考残差。用 3×3 而不是插值四边形，是因为查询点落在边缘半格时会被 clamp，只用四角会低估。
- 接收面分辨率低于 `MIN_CELLS` 时打印 `WARN`，标记 `res_warning`，并报告精度不足单元格数 `inadequate`。
- 容差扫描（0.005 / 0.02 / 0.20）输出射线数与 `inadequate`：容差过紧时单元格采样饱和、被计为精度不足。
- 自检用 128×128 直接射线求交作参照，输出命中率、最大/平均误差与上界违反数。
