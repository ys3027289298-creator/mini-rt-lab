# caustic

镜面-漫反射路径分类采样与焦散（flatland 2D 实验）。`make test` 跑自检。

## 模型

- 场景：面光源、Lambert 漫反射地板、一对近竖直微倾斜的平行镜面（光可在两镜间来回反射）。
- 路径按**镜面链 + 漫反射终点**分类，类 `k` 表示含 `k` 次镜面事件；`k=0` 是长度 1 路径（直接光）。
- 用**虚像展开**（mirror unfolding）把含镜面的折线拉直成一条直线求解，再前向追踪折叠回真实几何并做遮挡校验，保证只接受物理可实现的路径。

## 采样与权重

- 每条类用两种策略估计：光源面积采样、接收点余弦采样（沿确定性镜面链连接到光源）。
- 两策略用**幂启发式（指数 2）**做 MIS，权重非负且和为 1。
- **归一闸门**：`gate_pass` 逐样本校验权重和为 1（容差 1e-9），不通过则拒绝合成；估计器内部闸门失败会直接报错返回。

## 与参考比对的误差上界

- 参考：对光源坐标高分层求积（2048 层）。
- Hoeffding 上界：由几何推出每个光源策略项的确定性界 `f/pL <= Le·L/rmin²`（余弦 ≤1、每段长度 ≥ 最小物距 `rmin`），
  则 `P(|mean-ref| > ε) ≤ 2exp(-2Nε²/b²)`；并有构造性检查确认所有实测项不超过该界。
- Chebyshev 上界：`ε = sqrt(var/(N·α))`，用样本方差，随 N 增大收紧。

## 长度 1 退化

`k=0` 时展开退化为光源到地板的直线，估计值与直接光的解析积分
（`∫ y²/((u-x)²+y²)² du` 的闭式原函数）逐项核对。

## 对照

朴素单向路径追踪（只从接收点发余弦光线、不做跨镜面连接）在 68% 的焦散像素上零命中，
RMSE 是 MIS 合成的两个数量级以上——量化展示了为什么朴素 PT「看不到玻璃下的焦散」。
