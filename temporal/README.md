# temporal

时域累积的历史权重自检。混合式为 `out = (1-a)*current + a*history`。

- **最优历史权重**：两帧方差为 `vc`、`vh` 时，最小化 `(1-a)^2*vc + a^2*vh` 得
  `a* = vc/(vc+vh)`，最小方差 `vc*vh/(vc+vh)`。`vc+vh=0` 时退回当前帧。
- **稳态方差下界**：固定权重 `a` 的递推稳态为 `s2*(1-a)/(1+a)`；权重受
  `a<=a_max` 限制时，下界为 `s2*(1-a_max)/(1+a_max)`。无上限的逐帧最优权重
  会得到 `V_n=s2/n`，因此正的下界依赖权重上限。
- **拖影像素**：以当前帧为真值，`|out-current|>tau` 记为拖影；比例超过阈值
  时报警。场景纹理带限、方差与运动无关，位移越大，历史偏差超过 `tau` 的像
  素越多，因此计数随运动量单调上升。
- **穷举校验**：网格搜索权重的最小方差与解析值的偏差不超过
  `(vc+vh)*h^2/4`，其中 `h` 为网格步长。

`make test` 跑自检。
