# layer

多种材质分层叠放时的能量补偿。

- 逐层解析合成：adding 方法，把层间多次反射的几何级数闭式求和，得到总反射率 `R`、总透射率 `T` 及每层贡献分解。
- 补偿系数：对朴素单弹射权重 `w_k = (Π t_j)·r_k` 解 `c_k = contrib_k / w_k`，使 `Σ c_k·w_k = R`，并给出残差上界 `ebound`。
- 能量守恒：物理输入（每层 `r+t ≤ 1`）下 `R+T ≤ 1 + ebound`，总能量不超过入射。
- 冲突报告：系数无解时返回冲突层索引——非物理层（`r+t>1`）、镜面谐振腔（级数发散）、或朴素模型不可见但仍贡献能量的层。

`make test` 跑自检。
