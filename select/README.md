# select

按几何分布与查询模式在加速结构与参数间做启发式选择，并与穷举最优比对。

候选：暴力扫描、均匀网格（分辨率 4/8/16）、BVH（叶大小 1/2/4），共 7 个。

判据（`est_cost`，只看统计量、不建结构）：

- 场景统计：图元数、场景各轴范围、图元平均尺寸、根节点中位分裂的子盒表面积比 `rho`（衡量包围盒重叠）；
- 查询模式：查询数、相干性（随机/平行/聚点）、命中场景盒的光线比例 `hit_frac`；
- 暴力：`q*n`；网格：建造成 `格数+n*dup`，查询 `路径格数+平均占用`；BVH：建造成 `2n/leaf` 节点，查询按 `rho` 几何级数估计逐层到达节点数。

比对：代价单位为确定性操作计数（节点访问=1，图元测试=2），套件覆盖 8 类几何分布 × 2 种规模 × 2 种查询量 × 3 种查询模式共 96 场景。输出 `bound`（启发式/穷举最优的最大偏差比，仅对该场景族有效）与 `fail=` 行（ratio > 1.5 的判据失效场景）。

已知判据失效模式：

- 深层重叠：根部分裂 `rho` 小但深层子树完全重叠（如 giants+spot，巨大图元贯穿多层），几何级数假设失效，BVH 代价被低估；
- 双峰尺寸：平均尺寸掩盖少数巨大图元，网格 `dup` 估计失真；
- 查询空间倾斜：聚点查询打在热点上时，平均占用不等于路径上的占用。

`make test` 跑自检（含空场景/空查询拒绝、各结构命中一致性、上界合理性）。`-DDEBUG_COSTS` 构建可打印各场景全部候选的实测与估计代价。
