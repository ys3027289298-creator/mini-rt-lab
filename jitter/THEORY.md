# 最优抖动幅度：频谱上界推导与穷举核验

## 0. 问题与记号

均匀抖动（stratified jitter）采样：格距 `T=1`，样本位置

```
t_n = n + U_n,   U_n iid ~ Uniform(-a, a),   0 ≤ a ≤ 1/2
```

- `a=0`：`U_n≡0`，**退化为确定性格点采样**（本报告所有公式与代码在 a=0 连续成立）。
- `a=1/2`：满抖动，每格内全覆盖。
- 零均值平稳信号 `x(t)`，双边功率谱 `S(ω)`，归一化 `E = (1/2π)∫S dω = 1`。
- 基带 `B=[-π,π]`，奈奎斯特频率 `π`，混叠平移 `2πk`。
- 抖动的**采样核**是均匀分布的概率密度，其频谱即特征函数：

```
Φ_U(ω) = E[e^{jωU}] = sin(aω)/(aω) = sinc(aω)
```

sinc 的两个关键性质（上界推导的基石）：

```
|sinc(x)| ≤ 1,   |sinc(x)| ≤ 1/|x|  (x≠0)
```

---

## 1. 重构 MSE 的精确分解（Balakrishnan 1962 框架）

理想低通重构的每样本基带均方误差分解为两项：

```
MSE(a) = N(a) + A(a)

N(a) = (1/2π) ∫_B [1 - sinc²(aω)] S(ω) dω                    …带内抖动噪声
A(a) = (1/2π) ∫_B Σ_{k≠0} sinc²(a(ω+2πk)) S(ω+2πk) dω        …残余混叠
```

**物理图像（对应"闪"与"锯齿"）**

- `N(a)`：抖动把带内信号自身随机化，幅度越大噪声越大 → 画面**闪**。`N(0)=0`。
- `A(a)`：带外频率 `ω+2πk` 折叠进基带造成混叠（锯齿/摩尔纹）；采样核频谱 sinc 对高频混叠施加权重压制，幅度越大压制越强 → **锯齿减少**。
- 二者单调性相反（测试 `test_mse.py::test_monotonicity` 数值验证），故 `MSE(a)` 呈 U 型，存在最优折中点。

**a=0 的退化**：`sinc(0)=1`，于是 `N(0)=0`、`A(0)=A0 ≡ (1/2π)∫_B Σ_{k≠0} S(ω+2πk)dω`，恰好等于确定性采样的混叠能量。代码与测试 `test_zero_jitter_degenerate` 验证这一点。

## 2. 由采样核频谱推混叠误差上界

### 2.1 带内噪声上界

对所有 x，`1 - sinc²(x) ≤ x²/3`（由 `sin x ≥ x - x³/6` 展开可得，等号在 x=0 极限成立）。令 x=aω：

```
N(a) ≤ (a²/3) · (1/2π) ∫_B ω² S(ω) dω = m2_B · a²/3
```

其中 `m2_B` 是基带内二阶谱矩。**上界是 a 的二次增函数。**

### 2.2 混叠上界

混叠求和里每个频率 `u = ω+2πk` 都满足 `|u| ≥ π`（基带外最近邻）。用 `sinc²(x) ≤ min(1, 1/x²)`：

```
A(a) ≤ (1/2π)∫_B Σ_{k≠0} min(1, 1/(a²u²)) S(u) dω
     ≤ A0 · min(1, 1/(πa)²)
```

其中 `A0 = A(0)` 是确定性混叠能量。**上界在 `a<1/π` 饱和为常数 A0，在 `a≥1/π` 按 1/a² 衰减。**

### 2.3 总上界与最优幅度

```
U(a) = m2_B·a²/3 + A0/(π²a²)          (a ≥ 1/π 的有效分支)
```

最小化 U（对 a 求导置零）：

```
U'(a) = 2 m2_B a/3 - 2 A0/(π² a³) = 0
```

```
             ┌─────────────────────────┐
             │  a_U* = (3 A0 / (π² m2_B))^{1/4}   │   …上界最优幅度（闭式）
             └─────────────────────────┘
```

**凸性/唯一最小条件**：`U''(a) = 2m2_B/3 + 6A0/(π²a⁴) > 0` 恒成立，故驻点是 U 的唯一全局最小。

**分支条件（决定上界法是否可用）**

| 条件 | 结论 |
|---|---|
| `a_U* ≥ 1/π` 且 `a_U* ≤ 1/2` | 内点有效，上界法直接给可用幅度 |
| `a_U* < 1/π` | 驻点落在饱和区，1/a² 分支未生效；上界在该区只增不减，**上界过松，无法定位内点**，须改用精确驻点方程（代码状态 `sat:envelope_too_loose_use_exact_root`） |
| `a_U* > 1/2` | 可行域内 U 单调减，上界推荐**满抖动边界**（`boundary:full_jitter`），实际取 `clip(a_U*, 0, 1/2)` |

上界的严格性由测试 `test_envelope_is_upper_bound` 在全部网格点验证 `U_N≥N`、`U_A≥A`。

## 3. 小抖动闭式：四阶展开的最优幅度与存在条件

把 sinc² 在 a=0 展开：`sinc²(x) = 1 - x²/3 + 2x⁴/45 + O(x⁶)`。代入 MSE：

```
MSE(a) ≈ c2 a² + c4 a⁴
c2 = (2 m2_B - m2)/3          m2  = (1/2π)∫ ω²S dω   （全谱二阶矩）
c4 = (m4 - 2 m4_B)/90         m4  = (1/2π)∫ ω⁴S dω
```

`-c2` 的符号决定内点最优是否存在：

- **`c2 < 0`**（即 `m2 > 2 m2_B`，带外二阶矩占主导 → 混叠是主要矛盾）：存在内点最小，
  ```
  a4* = sqrt(-c2/(2 c4)) = sqrt( 30 (m2 - 2 m2_B) / (m4 - 2 m4_B) )
  ```
  附加条件 **`c4 > 0`**（四阶项为正把曲线拉回，否则四阶模型无界，需更高阶）。
- **`c2 ≥ 0`**：MSE 在原点即最小，**`a*=0`（确定性采样）**。这给出了"何时不该抖动"的可计算判据。

四阶式只在小 a 可靠；当 `a4*>1/2`（如高斯 σ=2.5 给 0.570）说明已超出展开有效区，须以精确驻点为准。

## 4. 精确驻点方程（基准真值）

对精确 MSE 求导（`d/da sinc²(aω) = 2 sinc(aω)·sinc'(aω)`），解

```
M'(a) = 0,  a ∈ [0, 1/2]
```

实现要点（实测中踩到的两个坑，已在代码修正并由测试固化）：

1. MSE 可以出现**多个驻点**：典型如高斯 σ=2.5，原点 a=0 是一个驻点（边界），另有一个内点驻点 a≈0.362 才是全局最小。必须枚举全部符号翻转 + 两端点、逐一比较 MSE 取全局最小，只取第一个根会误判（σ=2.5 早期实现因此错选）。窄带信号（σ≤2.0、洛伦兹 p3）则全程 M′≥0，全局最小就在边界 a=0。
2. 数值二阶导 `M''(a*)>0` 作为局部最小条件（三个内点用例实测 M″=0.57~2.52 均为正）；边界点单独标记。

解析导数与中心有限差分在所有用例、多个 a 上相对误差 ≤ 1e-3（`test_derivative`）。

---

## 5. 偏差上界：解析幅度相对穷举最优的距离

设 `â` 为某解析法给出的幅度，`a*` 为穷举全局最优，`Δ = MSE(â) − MSE(a*) ≥ 0`。

**强凸距离上界（主结果）**：若区间 `[min(â,a*), max]` 上 `M'' ≥ κ > 0`，泰勒展开给

```
Δ ≥ κ d²/2   ⇒   d ≡ |â − a*| ≤ sqrt(2Δ/κ)
```

再计入穷举网格自身的不确定度 `h`：

```
d ≤ sqrt(2Δ/κ_min) + h        （κ_min 取区间内 M'' 最小值，保证覆盖）
```

**Lipschitz 下界（仅核验，不能当上界）**：`Δ ≤ L d ⇒ d ≥ Δ/L`，`L = max|M'|`。它与上界夹住真实距离。

## 6. 数值结果

6 个谱用例（高斯 σ∈{1.5,2.0,2.5,4.0}、洛伦兹 p∈{2,3}），穷举网格 4001 点、步长 h=1.25e-4。完整数据见 `results/summary.json`。

### 6.1 精确驻点 vs 穷举（核心结论）

| 用例 | 穷举 a* | 解析驻点 | 实测距离 d | 关系 |
|---|---|---|---|---|
| 高斯 σ1.5 | 0.00000 | 0.00000（边界） | 0 | 完全一致 |
| 高斯 σ2.0 | 0.00000 | 0.00000（边界） | 0 | 完全一致 |
| 高斯 σ2.5 | 0.36175 | 0.36173 | **1.7e-5** | ≤ 1 网格步 |
| 高斯 σ4.0 | 0.48838 | 0.48832 | **5.7e-5** | ≤ 1 网格步 |
| 洛伦兹 p2 | 0.16400 | 0.16405 | **5.4e-5** | ≤ 1 网格步 |
| 洛伦兹 p3 | 0.00000 | 0.00000（边界） | 0 | 完全一致 |

**解析驻点在全部 6 个用例上落在穷举最优点的一个网格步之内**（图4左）。三个内点用例 `M''(a*)>0`（凸性条件满足，值 0.57~2.52）。

### 6.2 两个闭式近似的偏差与上界（内点用例）

| 用例 | 方法 | 幅度 | 实测距离 | 强凸上界 | 上界是否覆盖 |
|---|---|---|---|---|---|
| 高斯 σ2.5 | 上界法 | 0.4170 | 0.0553 | 0.0563 | ✓ |
| 高斯 σ4.0 | 上界法 | 0.5000(截) | 0.0116 | 0.0120 | ✓ |
| 洛伦兹 p2 | 上界法 | 0.3540 | 0.1900 | 0.2196 | ✓ |
| 高斯 σ2.5 | 四阶法 | 0.5703 | 0.2085 | 0.2437 | ✓（已超 ½，展开失效区） |
| 高斯 σ4.0 | 四阶法 | 0.5018 | 0.0134 | 0.0139 | ✓ |
| 洛伦兹 p2 | 四阶法 | 0.1304 | 0.0336 | 0.0387 | ✓ |

实测距离全部落在强凸上界之内（图4右），验证 `d ≤ √(2Δ/κ)+h` 有效。上界法在 σ4.0、四阶法在 σ4.0/洛伦兹p2 都落在穷举点附近（距离 ≤0.034）；上界法在窄带用例（σ1.5、洛伦兹p3）触发饱和分支，按规则回退精确驻点。

### 6.3 确定性退化与"不抖动"判据

- 所有用例 `N(0)=0`、`MSE(0)=A0`，且 `A0` 与独立计算的谱尾概率（高斯 `2·P(|ω|>π)`）5 位小数吻合。
- 窄带用例（σ1.5、σ2.0、洛伦兹p3）四阶判据 `c2≥0` 与穷举一致给出 `a*=0`：**信号带宽不足时最优就是确定性采样，抖动只会增加噪声无收益。**
- 高斯谱矩闭合值 `m2=σ²`、`m4=3σ⁴` 与数值积分吻合（`test_moments`），交叉验证谱矩实现。

> 重尾说明：洛伦兹 p=2 谱（尾 ~ω⁻⁴）的理论四阶矩发散，网格在 ±16π 截断给出有限 `m4`，其二阶矩闭合值 `w0²/(2p-3)=4` 与网格值 3.90 偏差 ~2.5%（截断误差）。因此洛伦兹 p=2 的四阶闭式 `a4*` 含截断近似，而精确驻点/穷举不依赖高阶矩，结论不受影响；p=3 谱尾 ~ω⁻⁶，二阶矩有限且闭合值通过测试。
