# jitter — 最优抖动幅度的频谱推导与数值核验

回答"抖动大了闪、小了锯齿，幅度取多少最优"。理论见 [THEORY.md](THEORY.md)，图见 `figs/`。

| 文件 | 作用 |
|---|---|
| `mse.py` | MSE=N(a)+A(a) 精确模型、采样核频谱上界、上界/四阶闭式最优、精确驻点、穷举、偏差上界 |
| `test_mse.py` | 60 项独立健全性测试（谱矩闭合值、a=0 退化、单调性、导数有限差分、上界有效性、驻点-穷举一致） |
| `make_figs.py` | 4 张图：MSE 分解、上界有效性、三种最优幅度对比、偏差距离 |
| `results/summary.json` | 6 个谱用例的全部数值结果 |
| `THEORY.md` | 完整推导、条件、上界、数值对照表 |

```bash
make          # = test + analyze + figs
make test     # 仅测试
```

核心结论：精确驻点 `M'(a)=0` 与穷举全局最优在所有用例上偏差 ≤ 1 个穷举网格步（1.25e-4）；
闭式上界最优 `a_U*=(3A0/π²m2_B)^{1/4}` 带分支条件，窄带信号判据 `c2≥0` 给出 `a*=0`（确定性采样退化）。
