# texture

`make test` 跑自检。

mip 金字塔 + 各向异性过滤。像素脚印取 UV 雅可比的椭圆 `E = J·Jᵀ`
（`J = [[du/dx, du/dy], [dv/dx, dv/dy]]`，单位为纹素/像素，1 表示 1 纹素/像素）：

- **级别**：由短轴定，`lod = log2(max(minor, 1))`，钳到 `[0, 8]`；`level0/level1` 与 `blend` 给出三线性混合权重。
- **采样数**：`taps = ceil(major / max(minor,1))`，沿长轴方向等距取 `taps` 个（三线性）tap 平均。
- **截断**：比值超过 `MAX_TAPS=16` 时 tap 数截为 16，`Plan.clamped` 置位，同时 `g_truncations` 计数一次（每像素一次）。tap 间距改为 `major/16`，仍覆盖整个长轴。
- **零导数**：雅可比全零时无法估 LOD，`Plan.fallback` 置位并取最近级（level 0）双线性，不做三线性。

## 与逐像素精确滤波比对

参照 `exact_box`：把旋转矩形在纹素格上做 polygon clipping，求精确面积平均，
即每个像素真正想要的滤波结果。`flicker` 让像素滑过一个纹素、取与精确滤波偏差的 RMS，
再除以纹理标准差——这正是"远处闪烁"的可测代理。

自检输出的数（误差均除以纹理标准差）：

| 量 | 结果 |
|---|---|
| 精确性（1 纹素脚印、线性渐变） | 误差 ≤ 2.5e-8，任意旋转与分数 LOD |
| 平滑纹理 700 个脚印 | RMS 0.005，最大 0.010；同轴基线 RMS 0.138 |
| 细节纹理 700 个脚印 | RMS 0.054，最大 0.324；同轴基线 RMS 0.230 |
| 掠射（2×64 纹素脚印） | 各向异性误差 9.6e-4，同轴基线 0.399；闪烁 0.002 vs 1.41 |

## 误差上界

两个上界，测试里对全部 700 个脚印逐一验证"实测 ≤ 上界"：

- `error_bound_local(p, u, v)`：两个核的支撑集之内纹理的**取值范围**。不需要任何平滑假设，逐像素可算，是实际引用的那个（在最坏点上用了上界的 14%，其余 ≤ 4%）。
- `error_bound_lipschitz(p, lip)`：闭式，`lip` 为纹理 1 纹素斜率上界。精确盒与 tap 平均都是落在脚印外扩 `s = 2^level` 的区域内的凸组合，该区域 L1 直径为 `(major+minor)(|cosθ|+|sinθ|) + 4s`，故误差 ≤ `lip ×` 该直径。实测用量 0.4%–1%。

## 已知取舍

mip 的核是级网格上的方形 tent，不是随脚印旋转的椭圆盒。所以三线性部分在
`minor` 方向上略宽（最多过半级），且旋转时按网格轴各多抹 `s`——
这正是闭式上界里 `2s` 项与 `4s` 项的来源，也是细节纹理最大误差 0.32 的构成。
要提高精度需 EWA 类椭圆加权，本模块刻意保持"选级 + 多 tap"的常规结构。
