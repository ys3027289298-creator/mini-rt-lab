# parity

离线路径追踪与联机光栅化两条渲染管线的**口径对齐**模块。目标不是让两种
算法产出完全相同的图（它们的传输模型本质不同），而是确保除"算法结构差异"
之外的一切——光照单位、纹理过滤、色调映射——走**同一份代码、同一个函数**，
从而让逐像素差异可以被干净地归因。

## 三处口径如何对齐

| 口径 | 共享实现 | 两条管线的调用方式 |
|---|---|---|
| 辐射度量 | `radiometry.c` | 点光用辐射强度 W/sr、逆平方衰减；环境用辐射度；BRDF 为 Lambert/GGX。两边都只调 `shade_direct()` / `ambient_term()`，阴影射线共用同一 BVH 可见性测试 |
| 纹理过滤 | `texture.c` | 唯一入口 `tex_sample()`：repeat 包裹 + 双线性 4-tap，纹理 sRGB 创作后统一转线性存储。RT 在命中点 UV 采样，光栅在透视校正插值后的 UV 上采样同一个函数 |
| 色调映射 | `tonemap.c` | 同一条 ACES(Narkowicz) 曲线 + 同一 sRGB 传递函数，`tonemap_image()` 处理两边的 HDR 缓冲 |

其余共享件：`camera.c`（针孔相机，射线生成与投影互为逆运算）、`tri.c`
（中位数分裂 BVH，光栅的阴影射线也走它）、`image.c`（统一 HDR/PFM、LDR/PPM）。

两条管线唯一的**结构性**差异：路径追踪有间接弹射（余弦/GGX 重要性采样，
默认 4096 spp、最多 3 次弹射），光栅化只算直接光 + 闭式环境项。

## 构建与运行

```
make            # 构建 selftest / pathtracer / rasterizer / diffimg
make test       # 快速自检（64 spp）
make parity     # 完整对比：4096 spp 出图 + 逐像素差分 + 直方图
```

产物（`out/`）：

- `rt.ppm` / `rast.ppm`：两条管线色调映射后的 sRGB 图
- `rt_hdr.pfm` / `rast_hdr.pfm`：线性 HDR 辐射度
- `diff_report.txt`：逐像素差分统计（MAE/RMSE/分位数/ASCII 直方图）
- `diff_hist.csv`、`diff_hist.svg`：差值直方图数据与图表
- `diff_heat.ppm`：差值的空间热力图（蓝=一致，红=差异大）

## 实测结论（240x180，4096 spp）

直接光对照实验（关闭 RT 的所有弹射，与光栅同传输模型）：

```
0-bounce RT vs raster:  HDR RMSE = 0.0094   99.7% 像素近逐位一致
```

逐材质拆分（直接光）：地面（带纹理）与两个盒子 RMSE 全为 **0.0000**，
球面仅余 0.007–0.06 的细分几何差。

完整渲染的逐像素亮度差（sRGB 0–255 级）分布：

- **约 52% 像素差值落在 [0,8)**，约 72% ≤ 8，约 76% ≤ 16
- 直方图呈双峰：主峰在 [0,8)（背景 + 大部分直接光表面）；
  次峰在 [40,48) 一带，空间上集中在物体所在的中下部
- 顶部背景行差异为 0；HDR 线性空间 RMSE ≈ 0.097

剩余差异的归因（已通过控制实验隔离）：

1. **间接弹射（主因）**：RT 的全局弹射带回颜色溢色与间接照明，
   均值辐射度 0.250 vs 光栅 0.197。这是算法结构差，不是口径错误。
2. **球面几何表示（次因）**：RT 解析求交 vs 光栅 24x48 细分网格，
   命中点平均偏差约 1e-3，在 GGX 高光区被放大；轮廓边缘有零星像素归属不同。

## 开发中修掉的对齐陷阱（selftest 防回归）

- 阴影射线偏移过小导致细分曲面**自遮挡（shadow acne）**，高光被误杀
- PFM 行序（bottom-up/top-left）读写不互逆，造成两图空间错位
- AABB slab 测试对零厚度包围盒（地面）的 inf 除法误判
- 球细分三角形数超过 `MAX_TRI` 静默溢出，三个球被错误合并到同一材质
- 地面三角形跨越相机近平面，整三角形被错误剔除
