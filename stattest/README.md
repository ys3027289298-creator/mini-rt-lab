# stattest

卡方拟合优度检验 + 功效分析：判断"噪点是真的随机，还是采样器有偏"。`make test` 跑自检。

## 检验设计

- **H0**：样本 iid ~ 已知分布 p（分箱概率）；**H1**:q ≠ p，偏差用卡方散度
  δ² = Σ(q_i−p_i)²/p_i 度量。
- 统计量 X² = Σ(O_i−Np_i)²/(Np_i)。H0 下 X² ~ χ²_{K−1}，拒绝域 X² > c,
  c 取 χ²_{K−1} 的 1−α 分位数（精确计算，**误报率 = α**)。
- **功效曲线**：一阶理论 X² ~ 非中心 χ²_{K−1}(λ=Nδ²) 在中等 λ 处系统性高估功效
  （实测 0.945 vs 模拟 0.903)，会让最小可检测偏差偏乐观。这里改用
  **多项分布下 Pearson 统计量的精确均值/方差（阶乘矩闭式）+ Patnaik 两矩近似**
  X² ≈ g·χ²_h，与模拟吻合到 <0.01。
- **最小可检测偏差**:δ_min 由 power(δ) = 1−β 二分反解（对代表性 shift 备择族
  q0 = 1/K+ε;df=1 时一阶理论有闭式 λ_min = (z_{1−α/2}+z_{1−β})²)。
- **判定规则**:
  - X² > c → 拒绝 H0（任何时候有效，误报率已控）;
  - X² ≤ c 且 power(δ*) ≥ 1−β → 接受 H0（分辨率 δ*);
  - X² ≤ c 且 power(δ*) < 1−β → **不报结论**，报告当前功效和所需样本量 n_needed。

## 自验结果（K=16, α=0.05, 每次试验 N=1000, M=4000 次试验）

| 检验 | 解析值 | 实测值 |
|---|---|---|
| 误报率（已知均匀 RNG) | 0.0500 | 0.0515 |
| 功效 @ δ=0.083 | 0.309 | 0.301 |
| 功效 @ δ=0.124 | 0.657 | 0.664 |
| 功效 @ δ=0.165 | 0.907 | 0.903 |
| δ_min（目标功效 0.80) | 0.1437 | 实测功效 0.792 |

## 功效曲线

`power_curve.png`（由 `power_curve.csv` 经 `plot_power_curve.py` 生成）:
三条曲线 N=200/1000/5000，圆点为各自 δ_min。例如 N=1000 时 δ_min≈0.144——
偏差小于这个量级时，1000 个样本不足以下结论，只能给功效。

## 应用：检验 material 的余弦加权采样器

w = cosθ 的 pdf 为 2w，故 t = w² 在正确采样器下均匀。把 t 分 K 个等概箱做卡方：
正确实现（z=√(1−u1)）在 N=4000 时 X²=9.4 < 25.0 且功效 0.99 → 接受；
错误实现（z=√(1−u1²)）X²=3070 → 拒绝。

注意：卡方拟合优度假定样本 **iid**。分层/QMC 序列（如 sample/ 的 Halton)
按构造就不是 iid，直接套用会在大 N 时必然拒绝；应检验其底层均匀随机源，
或只对 iid 抽样使用本检验。
