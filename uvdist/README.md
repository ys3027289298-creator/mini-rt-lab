# uvdist

逐三角形 UV 失真检测 + 采样联动。

## 度量

对三角形 i，世界坐标顶点 `p0,p1,p2`、UV `q0,q1,q2`：

```
A_geo = 0.5 * |(p1-p0) × (p2-p0)|
A_uv  = 0.5 * |cross2(q1-q0, q2-q0)|
density = A_uv / A_geo                    (纹理密度)
r = density / ref                         (相对目标密度的面积比)
s = log2(r)                               (有符号 log2 拉伸)
D = 2^{|s|} = max(r, 1/r)                 (无符号面积失真，D ≥ 1)
```

`ref` 为参考纹理密度（默认取不变形三角形）。`D == 1` 当且仅当该三角形面积比与目标一致；
`|s| = 1` 表示 UV 面积差 2 倍，`|s| = 2` 差 4 倍。`s > 0` 过密（纹素被压缩），
`s < 0` 稀疏（贴图被拉伸放大）。

每个三角形的两个面积同时用另一条独立公式再算一次（3D 用海伦公式、UV 用鞋带公式），
导出时报告最大偏差；密度还与切线映射 SVD 的 `1/(σmax·σmin)` 对拍。所以"与逐三角形解析面积比一致"
是每次运行被验证的，而不是断言的。

## 采样联动

按权重 `w_i = A_geo_i · 2^{k|s_i|}` 划分采样预算（默认 k=1）。**零失真三角形（s 精确为 0）
权重就是面积本身，因此不会拿到超过其面积占比的采样**——零失真区域不被多采样。
整数分配用最大余数法，预算精确用尽，结果确定。

## 构建 / 运行

```sh
make test      # 自检：闭式解用例 + 独立公式对拍 + 零失真不变式
make export    # 生成 out/ 下的 CSV、热图与汇总
```

`./uvdist --export DIR [--threshold D] [--budget N]`

## 输出 (`--export`)

| 文件 | 内容 |
|---|---|
| `report.html` | 自包含报告：热图内嵌、比例图例、按区域分配表、超阈值表、全表视图 |
| `stats.csv` | 每三角形：面积、密度、`s`、`D`、切线奇异值、条件数、采样数 |
| `flagged.txt` | `D > 阈值` 的三角形索引 |
| `summary.json` | 汇总、对拍残差、零失真采样审计、`flagged_indices` |
| `uv_heatmap.png` | 纹理空间中的 `D` 热图 |
| `world_heatmap.png` | 世界空间中按三角形着色的 `D` |
| `sample.png` | 世界空间中的每单位面积采样数 |
| `uv_cond.png` | 条件数（检测保面积的剪切型失真） |
| `checker.png` | 棋盘纹理经 UV 映射渲染到几何上——直接看拉伸 |

PNG 由内置的最小 deflate 编码器生成（固定 Huffman + LZ77），无需 zlib；
`report.html` 把图片以 data URI 内嵌，离线可直接打开。

测试网格为 12×8 平面片：第 0–1 列 UV 放大 4 倍（`s=+2`，`D=4`），
第 2–7 列 UV 不变（`s=0`），第 8–11 列 UV 缩小到 1/4（`s=-2`，`D=4`），
并叠加 `0.20·v` 的 shear（行列式为 1，不改变面积与 `s`，只抬高条件数）。
在失真 / 零失真面积各占一半的测试网格上，零失真三角形只拿到 20% 的采样预算（其面积占比为 50%），
且 `zero_distortion_oversampled = 0`。

## 自检覆盖

- 单位正方形 / 2×1 / 0.5×0.5 / 纯剪切 UV 映射的闭式解（`s`、`D`、奇异值、条件数）
- 面积比与独立公式（3D 海伦、UV 鞋带）逐三角形对拍，残差 < 1e-12
- 密度与切线 SVD 的 `1/(σmax·σmin)` 对拍
- 分配：全零失真精确 50/50；单三角形 4 倍失真得 20/80；
  两个零失真 + 一个 4 倍失真得 334/666（最大余数），预算精确用尽且确定
- 测试网格 192 三角形全部有效；零失真三角形采样占比严格低于面积占比
