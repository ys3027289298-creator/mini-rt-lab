# density

按每格误差贡献分配采样密度，`make test` 跑自检。

- 误差模型 `e_i = w_i * sigma_i^a / N_i^b`，方差目标 `(a,b)=(2,1)`、标准差目标 `(1,1/2)`。
- 最优密度 `rho_i ∝ sigma_i^(a/(b+1))`：方差目标 ∝ `sigma`，标准差目标 ∝ `sigma^(2/3)`。
- 输出均匀密度误差与最优误差之比 `E_u/E* = k^b * Σc_i / (Σc_i^(1/(b+1)))^(b+1) ≥ 1`，仅有 `c_i` 全等时取等号。
- 整数分配用最大余数法，`min_i N*rho_i > 1` 时给出舍入上界 `E_int/E* ≤ (1-1/min_share)^(-b)`；自检对穷举整数最优做三向验证。
- 空区域（`k<=0` 或总测度为零）拒绝，返回 `DENS_EMPTY`。
