# spot

`make test` 跑自检。

半影半径把光锥的两项分开推：

    R = rho * dtheta / cos(alpha)

`dtheta` 由 10-90 等照度环带的立体角反解 `dOmega = 2*pi*(cos t90 - cos t10)`（对称环带下为
`2*asin(dOmega / (4*pi*sin te))`），`rho` 为边缘点到光源的距离，`alpha` 为边缘光线在接收面上的入射角。
把环带按 `tan` 而非 `arc` 精确投到平面上，就是第二阶形式
`W = rho*[sin(h)/cos(a+h) + sin(h)/cos(a-h)]`，h = dtheta/2。

锯齿像素数：像素间距为 `h`、半影 10-90 宽度为 `W` 时，落在过渡带里的像素数
`N ≈ W/h`，而单个像素的强度跳变上界 `A_max ≈ 1.5/N = 1.5h/W`。所以 W 增大时 N 线性上升、
单像素跳变按 1/W 下降：半径越大越平滑（阶梯噪声小），但边缘越糊（过渡越宽）。
两者由同一个 W 驱动，方向相反。

自检同时跑三组不同距离与入射角的接收面，量出 10-90 剖面宽度并与预测对比；
若把入射角项写成乘 `cos(alpha)`，实测/错误值应恰为 `sec^2(alpha)`，测试用 C_far 组
（cos=0.42262，sec^2=5.5989，实测比 5.6059）验证符号。
