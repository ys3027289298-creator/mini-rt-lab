# render

确定性分块并行渲染。`make test` 跑自检。

确定性约定（改动时不要破坏）：

- **分块**：图像划分为 `tiles_x × tiles_y` 个整像素矩形块，每块只写自己的像素区间，
  线程之间无共享写，因此结果与调度顺序无关。分块按比例划分，保证覆盖每个像素且不重叠
  （`covers_all_pixels` 用哨兵值检查）。
- **样本顺序**：每个像素按样本索引 `0..spp-1` 升序累加；随机流由 `(px, py, sample)`
  播种（PCG 哈希），所以第 k 个样本的值不随 spp、分块或线程数改变。
- **归约顺序**：用 Neumaier 补偿求和，结果是输入序列的纯函数；序列固定，因此各种
  分块/线程配置逐位一致。输出归一化 `-0.0f` 为 `+0.0f`。
- **构建**：`-ffp-contract=off`，且不使用 `-ffast-math`，避免 FMA 合并和重结合
  造成跨构建/跨机器的差异。

参数校验（`render()` 返回码）：`1` 图像/`spp` 非法，`2` 分块数为 0 或负数，
`3` 线程数非正，`4` 分块数溢出，`5` 线程创建失败。

自检会打印 `image_hash`，可直接用于跨运行、跨机器比对。
