# mis

多策略重要性采样（MIS），balance heuristic 组合两个无偏策略，含解析积分
无偏性校验、等样本预算方差对比、权重和守卫与理论界。`make test` 跑自检。

## 问题与模型

光泽微片对一个叶瓣形光源的反射，被积函数是三个因子的乘积：

```
f(w) = rho/pi * (R·w)^e1 * (L·w)^e2 * (n·w)
```

两套采样策略各只匹配一个因子：

| 策略 | PDF | 匹配 |
|---|---|---|
| A：BRDF 重要性采样 | `pA = (e1+1)/(2pi) (R·w)^e1` | BRDF 叶瓣 |
| B：光源重要性采样 | `pB = (e2+1)/(2pi) (L·w)^e2` | 光源叶瓣 |

单策略估计量 `X_i = f/p_i` 都无偏，但各自在另一个叶瓣区域失配，
表现为「一套偏暗、换一套过亮」。

## 组合与权重守卫

balance heuristic 权重 `w_i = p_i/(pA+pB)`，配对采样的多样本估计量：

```
F = wA(w_a) f(w_a)/pA(w_a) + wB(w_b) f(w_b)/pB(w_b)
  = f(w_a)/(pA+pB)(w_a) + f(w_b)/(pA+pB)(w_b)
```

- 无偏性：`E[F] = JA + JB = I`，其中 `JA = ∫ f·pA/(pA+pB) dw`，
  `JB` 同理，`JA+JB=I`（程序用求积数值验证该恒等式）。
- 守卫：每个样本都检查 `wA+wB == 1`（容差 1e-12）；若 `pA=pB=0` 而
  `f≠0`（不可采样点上有非零贡献）则判定失败并计数，全部通过才允许合成。

## 无偏性校验（scene 1，解析真值）

Lambert 微片 + 均匀灯帽（中心与法线夹角 gamma，半角 tc）：

```
I = rho (1-cos²tc) cos gamma
```

余弦半球采样与均匀灯帽采样两个单策略及 MIS 估计量均在 5σ 容差内命中
解析积分；守卫零失败，并额外构造 `pA=pB=0, f≠0` 用例确认守卫会报警。

## 方差对比（scene 2，求积真值，等总样本预算 2m）

叶瓣中心分离（R 倾角 35°，L 倾角 65°，e1=8，e2=16），中点求积
（1024×2048 网格，已做网格收敛与独立 Python 交叉验证）给出每样本方差常数：

| 估计量 | 每样本方差常数 | 比值 |
|---|---|---|
| 策略 A | 0.0004864 | 1.88× |
| 策略 B | 0.0003214 | 1.24× |
| **BH-MIS** | **0.0002585** | **1.00×（最低，降 19.6%）** |

4096 次独立试验的蒙特卡洛实测（三档 m，全部 `MIS_LOWEST`、偏差在 5σ 内、
守卫零失败）：

```
 m= 16: varA=1.50e-5 varB=1.03e-5 varMIS=8.0e-6
 m= 64: varA=3.7e-6 varB=2.6e-6  varMIS=2.0e-6
 m=256: varA=1.0e-6 varB=6e-7    varMIS=5e-7
```

配对估计量单对方差 `Var(X) = MM - JA² - JB²`，其中
`MM = ∫ f²/(pA+pB) dw`；非负性由 Cauchy–Schwarz 保证。

## 理论下界与比较界

- 下界：`Var ≥ 0`，零方差当且仅当按 `p* = f/I` 采样（一般不可得）。
- BH ≤ 朴素等权 MIS：`2MM ≤ MA+MB`（对混合密度 `q=(pA+pB)/2` 的 C-S）。
- BH ≤ 混合分布采样：等价于 `JA²+JB² ≥ 2·JA·JB`（C-S，`JA=JB` 时取等）。
- Veach 一般上界（n=2）：`V[BH] ≤ min(V_A,V_B) + I²`，程序实测
  0.0002585 ≤ 0.0005895。

## 实现备注

- RNG 为 xorshift64* + splitmix64 种子派生，各试验独立流；叶瓣采样用
  `cosθ = u1^(1/(e+1))` 的功率余弦采样，其 PDF 即上表 `p_i`。
- 等预算记账：单策略每试验抽 2m 个样本，MIS 抽 m 对（共 2m 个）；
  单策略按 `1/(2m)` 归一，Veach 多样本估计量按对数 `1/m` 归一，二者期望均为 I。
