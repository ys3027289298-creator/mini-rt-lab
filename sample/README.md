# sample

采样与误差置信。`make test` 跑自检。

## 提供的东西

针对 **iid 蒙特卡洛估计**（一行 `mean`、一行 `var`）：

| 函数 | 作用 |
|---|---|
| `mc_ci(x, n, alpha, &stat)` | 由样本方差 `s²` 得标准误 `se=√(s²/n)`，给出 `mean ± z·se` 置信区间 |
| `mc_n_needed(var, target)` | 目标标准误 `target` 所需样本数 `n* = ceil(var/target²)`；不可达返回 `-1` |
| `mc_var_upper(x, n, alpha)` | 方差估计本身的不确定度给出的**单侧上界**（用四阶矩） |
| `mc_std_error(var, n)` | `√(var/n)`，`n<2` 或 `var=0` 时为 0 |

`z` 用正态分位数（Acklam 近似，误差 ~1e-9），不是 Student-t：libm 没有 t 分位数；小 `n` 时区间略窄，且 `σ` 来自同一批样本，区间只和方差估计一样可信。覆盖率和这些偏差由 `main` 里的实验直接测出来（`ci_coverage_nominal`）。

## 不可达

以下情况 `mc_n_needed` 返回 `-1`，不会给一个有限数：

- `var == 0`（所有样本相同，估计已无误差可减）
- `target <= 0`（要求零误差）
- 输入非有限（`NaN`/`inf`）

零方差时 `mc_ci` 仍给出退化的点区间 `[mean, mean]`；`n < 2` 或 `alpha ∉ (0,1)` 时返回区间无效。

## 自检里量了什么（f(u)=u² on [0,1)，真值 1/3，方差 4/45）

`main` 用固定种子的 splitmix64 重复 400 次，沿 n = 16…4096 的网格输出：

- `info_ratio`：实测 RMS 误差 / 理论 `√(var/n)`，每个 n 都应接近 1
- `info_coverage`：n=256 时 95% 区间实际覆盖率（≈0.95）
- `info_slope`：RMS 误差对 n 的双对数斜率，应 ≈ −0.5（收敛曲线）
- `info_n_emp` vs `info_n_star`：实测曲线插值出达到目标的样本数，对照理论 888.9，检查偏差 ±25%
- `info_upper_cover`：`mc_var_upper` 推出的 `n` 上界覆盖真值的比例（单侧 95%，实测≈0.93）

这些是**统计检验**，不是逐位断言；阈值按采样噪声放宽，种子固定所以结果可复现。

## 注意：分层采样不适用

`stratify()` 的每个分层只用一次，样本**不独立**，`σ/√n` 不适用于它——上面的置信区间只对 iid 采样有效。要评估分层/低差异序列，需要另外的误差模型（例如随机化 QMC 的重复批次），不在本模块内。
