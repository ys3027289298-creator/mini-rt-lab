# lowrank

渲染结果的逐块低秩压缩实验：按 B×B 块做 SVD 截断，用 Eckart-Young 给出
每个秩的最优误差下界，并测量真实序列化体积。`make test` 跑自检，
`make run` 出完整报告与曲线。纯 C 仓库里的一个独立 Python 实验目录
（numpy + matplotlib）。

## 用法

```sh
make test       # 自检：无损往返、下界、秩零退化、体积单调、偏差检测
make run        # 320x240 / spp=64 / 块 16 / 秩 0..16，写 out/
make run-small  # 小图快速跑
```

输出：

| 文件 | 内容 |
|---|---|
| `out/frame.npz` | 源帧（float32 线性 HDR） |
| `out/records.json` | 每组测量的残差、下界、体积、标志 |
| `out/report.md` | 体积与残差曲线两张表 |
| `out/curves.png` | 左：残差 vs 秩 + 下界；右：体积 vs 秩 |

## 方法

1. **分块与 SVD**。每个颜色通道切成 B×B 块（要求 B 整除图像宽高；否则零
   填充会让下界不再覆盖可见像素，代码直接拒绝而不是给一个不严谨的界）。
   对每块取 SVD，截到秩 r 得到最优 rank-r 近似。
2. **Eckart-Young 下界**。任意 rank-r 近似的平方误差不低于该块被丢弃的
   奇异值平方和 `Σ_{i>r} σ_i²`；对块求和即整个分块编解码的下界。截断 SVD
   恰好取等号，所以实测残差应当**贴着**下界、且因因子量化略高一点。
3. **体积**。因子（`U_r·diag(σ_r)` 与 `V_rᵀ`）定点量化成 16-bit（或 32-bit
   float）后，用真实的比特平面 + deflate 无损编码计量，并逐块校验往返一致。
   压缩比相对无损参照与未压缩原始字节两种口径都给出。
4. **退化：秩 0**。秩 0 不携带任何图像信息，自动退回无损路径，记录
   `fallback=true, reason=rank_zero`，平方误差为 0，体积等于无损参照。

`实测/下界 ≥ 1` 恒成立；低于下界说明实现有偏（下界漏项、块重复计数等），
驱动以非零退出码报错，自检里也用注入的偏置记录验证这个守卫确实会触发。

## 实测（320×240，spp=64，块 16，秩 16）

- 无损参照 **566.5 KB**（未压缩 921.6 KB）。
- 块 SVD r=1：**37.9 KB**（14.9× 于无损，24.3× 于原始）。
- 块 SVD r=8：**378.4 KB**（1.50× 于无损），RMSE 0.015。
- 块 SVD r=16：**731.7 KB**——高秩反超无损，这是预期：此时每个块保留全部
  16 个奇异值，因子数比原像素还多。
- 实测/下界 ∈ [1.000000, 1.004197]：全程贴着下界，最后一位偏差来自 16-bit
  因子量化。

详细数字见 `out/report.md`，图见 `out/curves.png`。

## 与全局 SVD 的关系

`global` 行是整通道不切块的 SVD。体积远小（r=1 仅 5 KB），但残差下降慢得多
（r=16 时 RMSE 0.087，块 SVD 已到 0.0004）。它是下界成立性的第二个验证
对象，也说明分块在同等秩下更贴合局部结构。两条曲线都用同一个 Eckart-Young
守卫检查。
