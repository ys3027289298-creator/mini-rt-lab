# photon

光子映射密度估计（KDE）的带宽选择，`make test` 跑自检。

## 模型

辐射度估计 `L(x) ≈ (1/(n h^d)) Σ K((x-x_p)/h) Φ_p` 是核密度估计。二阶核下：

- 偏差：`bias ≈ (h²/2)·μ₂(K)·∇²f`，即 O(h²)
- 方差：`var ≈ R(K)·f/(n·h^d)`，即 O(1/(n·h^d))
- 平衡 bias² 与 var 得 AMISE 最优速率 `h* ~ n^(-1/(d+4))`

`photon_bandwidth` 用 Silverman 规则给常数：`h = σ·(4/(d+2))^(1/(d+4))·n^(-1/(d+4))`（d=2 表面时 h ∝ n^(-1/6)）。`n <= 0` 返回负值拒绝。

## 自检内容

- 带宽随光子数按 `n^(-1/(d+4))` 收缩；零/负光子数拒绝
- 偏差界 ∝ h²、方差 ∝ 1/(n·h^d) 的标度关系
- h→0 时偏差界单调趋于 0（不发散）
- 对解析 N(0,1) 密度做 KDE，规则带宽的 RMSE 与穷举搜索最优带宽的误差对比
- x=0 处多轮平均的实测偏差不超过解析偏差上界（留 2 倍高阶项余量）
