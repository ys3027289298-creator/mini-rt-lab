# intersect

`make test` 跑自检。

无缝隙三角形求交。接缝漏光来自经典的 epsilon 窗口判定：射线落在两个三角形
共享边上时，两边都把边界点判成“外侧”，于是缝隙里露出背景。

本实现改用符号一致判据：

- 三条重心的分子是三条独立的边函数，由该边的两个顶点算出，不用 `1-u-v`；
- 三个符号同号即命中，**零视为在边界上**（同侧规则），共享边两侧都会接收该点；
- 符号的容差由生成该边函数的乘积量级推出，纯舍入噪声不会把边界点翻到错误一侧；
- 两套公式（Möller-Trumbore 代数、Woop 二维投影边函数）逐像素交叉验证；
- 退化三角形（非有限坐标、零/近零面积）单独分类、单独计数，不计为命中；
  射线与平面平行是独立标志，不属于三角形缺陷。

几何使用 `float`（与仓库其余模块一致），内部一律按 `double` 计算。

自检内容包括：

| 检查 | 判据 |
|---|---|
| `analytic_*` | 与整数精确边界判定逐像素一致，失衡数为 0 |
| `seam_*` | 共享对角线上逐点采样，漏光像素为 0，两公式一致 |
| `random_seam_*` | 随机非二进制几何、共享边，对 `long double` 解析解零差异、零漏光 |
| `negative_control_*` | 同一场景下朴素 float Möller-Trumbore 会漏光（约 0.34%），本实现为 0 |
| `degenerate_*` / `stats_*` | 退化三角形按原因分别报告 |
