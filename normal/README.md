# normal

面法线只按面算会让模型棱角分明。本模块做按面积与夹角加权的逐顶点法线重建并自检：

- **重建**：面法线 = 归一化叉积；面在某顶点处的贡献权重 = 面积 × 该顶点内角，按焊接位置累加后归一化。
- **着色法线比对**：逐顶点夹角误差；接缝（同一位置存在多个着色法线）单独统计接缝误差、着色法线跳变角。
- **解析法线比对（上界）**：若焊接点处各面法线与解析法线偏差均不超过 α，归一化非负加权平均的偏差 β 必满足 β ≤ α（单位向量上的凸组合），数值逐项验证。
- **接缝跳变为零**：重建按位置焊接，接缝两侧副本共享同一法线，角度跳变必须为 0。
- **退化面**：叉积近零（重复顶点 / 共线）的面单独列出，不参与任何平均；只被退化面引用的顶点法线标记为未定义。

`make test` 跑自检，打印各检查项 `name=0/1` 与 `all_ok`。
