# sphere — 数值稳健的光线/球体求交

`make test` 跑五个自检并把数据写到 `../artifacts/sphere/`；
`python3 plot_error.py` 读 CSV 生成三张误差图。

光线 `P(t) = O + tD`（`|D| = 1`），球心 `C`、半径 `R`。令 `L = O − C`，
代入 `|P − C|² = R²`：

```
t² + 2 b t + c = 0,   b = L·D,  c = L·L − R²,  判别式(半形) D = b² − c
```

## 1. 朴素公式为什么会坏

教科书写法 `t = −b ± √D`，有两处数值问题：

1. **近切点判负**。真切点 `D = 0`，但 `b²` 与 `c` 是两个 O(scale) 的数相减
   （`scale = b² + |c|`），浮点结果为 `D̂ = D + O(ε·scale)`。当
   `|D| ≲ ε·scale` 时 `D̂` 的符号与 `D` 无关；硬判 `D̂ < 0 → miss` 会把真实
   命中丢掉。本模块在擦边扫掠里复现了 1 个这样的丢命中（s ≈ 2896，
   见 `fig1_sweep.png` 左图橙叉）。
2. **相消**。`−b + sgn(b)·√D` 形式的根是两个相近数相减，有效位数按
   `D/b²` 比例损失，远距擦边时根的绝对误差可到 O(ε·scale/√D)。

## 2. 稳定公式（`sphere_stable`）

### 2.1 FMA 收窄舍入

```
b   = fma(Lx,Dx, fma(Ly,Dy, Lz·Dz))
L·L = fma(Lx,Lx, fma(Ly,Ly, Lz·Lz))
c   = L·L − R·R
D   = fma(b, b, −c)          // b² − c 只有一次最终舍入
```

FMA 把每次乘加的中间积保持无限精度，`b² − c` 与 `L·L − R²` 各自只有一次
最终舍入，把判别式的计算误差压到 `|D̂ − D| ≲ 2ε·scale`。
编译用 `-ffp-contract=off`，保证朴素版本不会被编译器悄悄加上 FMA 而掩盖
对比。

### 2.2 避免相消的根（Numerical Recipes 式 Vieta 稳定化）

```
q = −(b + sgn(b)·√D)        // 取幅度相加的分支，符号恒对、无相消
t1 = q;  t2 = c / q         // 另一根由根之积 t1·t2 = c 反推
```

两个根都不经过相近数相减；`q = 0`（仅当 b 与 √D 同时为 0）退化为重根。

### 2.3 判别式在零附近：取哪一侧

判据是**按计算精度归一化的容差带**，不是绝对零：

```
tol = τ·ε·scale,            τ = 8（覆盖 2~3 次舍入的误差累积）
D̂ < −tol        → 真 miss，返回 0
−tol ≤ D̂ ≤ +tol → 数值上与 D = 0 不可区分，钳 D̂ = 0，合并为单个切点根 −b，返回 2
D̂ > +tol        → 两个可分辨的根，按 2.2 求，返回 1
```

**取侧规则的物理含义**：带内的几何（无论真 `D` 在零的哪一侧）都无法在
float 下与切点区分，统一按切点状态（返回码 2）处理：

- `D̂` 为负但落在带内 → 不允许丢命中，钳 `D̂ = 0`，返回单个切点根 `-b`
  （"假命中"的多项式残差 `|F(t)| ≤ τ·ε·scale`，即该点在浮点意义下确实在
  球面上）；
- `D̂ = 0`（含钳零）→ 重根 `-b`；
- `D̂` 为正但落在带内 → 两根间距仅 O(√(ε·scale))，不可分辨；仍走 2.2 的
  Vieta 公式返回这两个无相消的近等根，但标记为切点状态，调用方不应把它们
  当作有几何意义的两个独立交点；
- 带外的负值才是几何上真正的偏离，保持 miss。

切点报告点的正确性用**多项式残差**而非径向距离衡量：远距大球时容差带的
几何宽度可达 O(√ε·B)，用 `||P−C|−R|` 作判据没有尺度意义；而
`|F(t̂)| = |t̂² + 2b t̂ + c| = |D̂| ≤ τ·ε·scale` 恒成立（自检实测
`max |F|/(ε·scale) = 0.27`，远低于 τ=8）。

## 3. 前向误差上界

设 `scale = b² + |c|`，`S = |L| + R`。判别式是 O(scale) 项的差，其绝对
误差 O(ε·scale)，经 `√D` 放大后根误差含 `scale/√D` 项；其余为根自身的
O(ε) 舍入。双根情形的先验上界：

```
|t̂ − t| ≤ K·ε·( scale/√D + |t| + S ),   K = 64（保守系数）
```

切点（带内）情形合并根的位移上界：

```
|t̂ − t_near|, |t̂ − t_far| ≤ K_t·( √(ε·scale) + ε·S ),   K_t = 4
```

上界不是拟合出来的：`scale/√D` 是判别式误差经平方根的条件数，`|t| + S`
覆盖 q 与 c/q 两次运算的舍入；K 是给 3 维点积、FMA、除法、排序留出的
保守操作数。随机 18 万光线 + 两个定向扫掠的**实测**最大系数：

| 量 | 先验系数 | 实测最大 |
|---|---|---|
| 双根误差 / `ε(scale/√D+|t|+S)` | 64 | **1.86** |
| 切点位移 / `(√(ε·scale)+εS)` | 4 | **0.34** |
| 切点残差 / `ε·scale` | τ = 8 | **0.27** |

误差随 `t` 量级的变化（`fig1_sweep.png`，R=1）：

- **擦边几何**（真 D = O(0.75)，b²、c ~ s²）：`scale/√D` 主导，根误差按
  **ε·s²** 增长；s 超过 `√(D/(τε)) ≈ 888` 后进入容差带，误差被钳在
  **√ε·s**（斜率从 2 降到 1 的拐点即带边界）；
- **中心命中几何**（D ~ s² 良态）：条件数项不放大，误差只按 **ε·s** 线性
  增长；
- s ≳ 2¹² 后 float 光线方向本身已无法编码擦边角（`ε·s²` 淹没 O(1) 几何），
   双精度参考也在网格舍入上交替 hit/miss，故图中该段不画，CSV 标
   `status=3`。这是 float 输入的表示极限，不是求解器问题。

## 4. 双精度参考与自检

`sphere_ref` 用同一套稳定数学在 double 下求解，作为参考解。五个测试：

1. **量级扫掠**（s: 2⁻¹⁶…2⁵⁶，两种几何）：逐点比对，验证 ε·s² / ε·s /
   √ε·s 三段律与上界；
2. **近切点扫掠**（B = 1 / 1e3 / 1e6，D 从 1e-9 到 1，正负两侧）：验证容差
   带随 scale 展宽（带宽 8εB²，根空间宽度 √ε·B），带内不丢命中、带外负侧
   保持 miss；
3. **20 万随机光线**（量级 2⁻⁴…2²⁰，随机球/半径/方向）：stable 丢命中数
   必须为 0，每条命中核对上界；
4. **球内出发**（c < 0，10 万条）：出口正根必须保留且准确；
5. **解析精确切点**（21 个量级）：状态必须是切点重根。
