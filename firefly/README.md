# firefly

按路径权重截断抑制孤立亮点（萤火虫），并给出偏差上界与无截断参考对比。

`make test` 跑自检，输出逐阈值表格：

- `bright`：孤立亮点像素数，`drop_pct`：相对无截断的下降
- `bound_abs` / `bound_pct`：解析证明的偏差上界（绝对值/相对均值）
- `meas_abs` / `meas_pct`：与无截断图像的实测偏差（公共随机数，`se3_pct` 为 3σ）
- `loss_pct`：相对能量损失；超过 `EPS` 标记 `LOSS`

自检项：包络确实支配真实重尾；上界覆盖解析真实偏差；实测偏差始终低于上界；
阈值过小时能量损失被报告；按 `TAU` 预算选出的阈值同时满足偏差与损失约束。
