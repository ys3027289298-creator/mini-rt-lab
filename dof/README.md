# dof

薄透镜弥散圆（CoC）模型 + 像素对角线限定 + 散景渲染自测。

限定式（长度单位 mm）：

```
r_lens = f^2·|s−d| / (2·N·d·(s−f))     薄透镜弥散圆半径
r_eff  = sqrt(r_lens^2 + r_min^2)      限定式，r_min = p_diag/2
```

`p_diag` 为像素对角线。像素积分等效于半径 `p_diag/2` 的圆盘核，卷积二阶矩相加，
因此限定式两端极限：

- `d → s`（贴对焦面）：`r_eff → p_diag/2`，不收零；
- `d → ∞`：`r_eff → sqrt(r_∞^2 + r_min^2)`，`r_∞ = f^2 / (2·N·(s−f))`。

孔径越界（`1 ≤ N ≤ 64`、`f/N ≤ 100mm`、`d > f`）的配置不渲染，单独报告。

`make test` 跑自检（含两端极限的实测验证）。
`make bokeh` 用 f=25/50/85mm 各渲染一张散景图到 `../artifacts/`，
每张 5 个离焦距离，打印实测半径与解析对照表。
